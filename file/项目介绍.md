## 一、项目是什么

**xiaomengresume** 是一款 **clean-room 从零构建的桌面简历编辑器**（Electron 离线应用），定位一句话：

> **开源免费 · 隐私优先 · 防盲信 AI 的简历工作台**

三大信任承诺（写进 README 首屏，任何界面文案不得与这三条矛盾）：

| 承诺 | 含义 |
|---|---|
| **真正免费** | 无水印、无付费墙、无隐藏收费、功能不阉割 |
| **数据主权** | 所有数据存本机、代码开源可审计、AI 用 BYOK（自带 Key） |
| **人工掌控** | AI 是辅助不是替代；导入简历走"三步核对"，绝不盲信 AI |

## 二、产品定位

- **形态**：单机离线桌面应用，无服务器、无账号体系
- **分发**：Electron 打包 exe / dmg / AppImage + 免安装便携版；GitHub Releases 发布
- **AI**：可选增值，BYOK，密钥加密存本地；**只做辅助编辑（润色/语法/匹配度），禁"一键生成简历"**（招聘官已吐槽 AI 简历同质化）
- **许可**：MIT 开源（个人第一款项目，以信任与口碑立身）
- **商业化**：免费开源，无订阅、无计费、无账号（天然规避竞品最大差评源——付费墙与取消难）

**界面形态（2026-08-09 迭代定案）**：默认初始页 = 独立欢迎界面（**品牌图标**（material/图标.png）欢迎卡 + 新建/打开引导）；简历主功能区**四大入口**（新建简历[空白/导入二级选择] / 打开简历 / 简历管理[批量删除 + **批量导入**] / 岗位管理[状态含「未投」+居中央模态框]）；编辑器 = **模块主分区**（模块卡网格 → 单模块编辑分区 + 返回；基本信息 = **图片/姓名与职业/标签信息三透明模块**内联编辑 + 拖拽排序）；基本信息标签 = **图案选择 + label 自由编辑**（预览/导出同步、长内容自动缩字号）；AI 设置 = **四内置服务商全开放编辑**（四字段文字标签 + 默认值/重置/清除）+ 自定义 + 检测模型 + **提示词分区（简历 4 卡 + 豆包视觉独立）**；主功能区子卡片 = **四宫格布局**（一行两个，奇数右侧）。细节见《项目功能.md》。

**差异化三板斧**（调研结论，原始调研见 rubbish 归档《竞品与用户反馈调研.md》）：
1. **桌面形态** —— 离线能力强、打印控制精确、文件管理优于 Web 工具；
2. **三步核对导入（独有）** —— 竞品全是"一键导入"，本项目把"防盲信 AI"做成信任设计；
3. **中文原生** —— 海外工具 AI 中文生硬，国内工具普遍收费。

## 三、用户与痛点

| 目标用户 | 核心痛点 | 本项目回应 |
|---|---|---|
| 求职者（应届/跳槽/转行） | 排版繁琐、内容空洞、ATS 被筛 | 结构化表单 + 实时 A4 预览 + 所有内置模板默认兼容 ATS（设计保证） |
| 隐私敏感用户 | 简历数据被存第三方服务器 | 全本地存储 + 开源可审计 + BYOK |
| 被付费墙坑过的用户 | 免费版水印/限次、试用自动转订阅 | 彻底免费、无水印、无账号无订阅 |
| 有旧简历要迁移的用户 | 数据锁定、导入"盲信 AI"出错 | 三步核对导入 + JSON 备份可迁移 |
| 怕"AI 简历"翻车的人 | 招聘官吐槽 AI 简历千篇一律 | AI 只做辅助编辑，人工掌控最终内容 |
