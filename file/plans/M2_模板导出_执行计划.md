## 三、ATS 实况研究结论（2026-08-08 · 5 源交叉验证）

**ATS 本质**：非"筛选门卫"，是快速粗糙的文本提取器——剥纯文本 → 按字段塞数据库（姓名/头衔/日期/技能）→ 供招聘官搜索排序。**不看视觉设计**。

**读取 vs 丢失**：

| 正常读 | 丢失/乱序 |
|---|---|
| 可选中文字（真实文本层） | 图片/图标内文字（0 字符） |
| 单栏 + 标准标题 + 标准字体 | 双栏/表格/文本框/页眉页脚（文本交错或跳过） |
| | 未嵌入自定义字体（缺字形→乱码）；加密 PDF；>2MB |

**关键事实**：**字号/行距/间距/页边距/主题色不进文本层，对 ATS 零影响**（视觉属性）。

**v1.0 架构免疫清单**：单栏定案（防最大杀手）✅ / printToPDF 矢量（文本层天然存在）✅ / SVG 装饰图标不承载信息 ✅ / Chromium 打印自动子集嵌入字体 ✅ / 用户可调参数全不影响 ATS ✅。

**→ 结论（D7）**：分级提示 = 过度设计（强提示档无触发入口）。砍为导出屏静态说明 + 保留一键恢复默认。需修订《项目实现情况.md》#29 拍板记录（F4 修订段落）。

### 步骤 2：F5 导出（D10/D12/D13 + 模态弹窗 D4 + 多页语义 D5）

**2a. IPC 契约**（冻结于 `src/shared/`，照 F5 落地点）：
- `ExportFormat = 'textPdf' | 'imagePdf' | 'image' | 'json'`
- `export:run({ format, folderPath?, imageFormat?, quality? })` → `{ canceled, filePath?, error? }`
- 进度事件 `export:progress`（phase: measure/render/print/write; ratio）
- preload 暴露 `window.electronAPI.export.run`
- 现有 `print:pdf` 保留（M0 冒烟链路），`export:run` 新增强化

**2b. 导出屏 = 模态弹窗（D4）**：
- 顶栏加「导出」按钮 → 弹窗：4 格式卡片（文字版 PDF ✅ / 图片版 PDF ⏳v1.1 / 图片 ⏳v1.1 / JSON ✅）+ 目标位置（默认 简历存储位置 F21 > 上次记忆 > 下载目录）+ 「选择文件夹」
- 图片版 PDF / 图片 置灰标注「即将在 v1.1 提供」（i18n `export.commingSoon`）
- **页数提示（D5/D12）**：弹窗内显示「内容约 N 页」（后台预渲染测量）；N=1 → 直接导出一页；N>1 → 「全部导出（N 页）」默认 + 「仅第一页」（标注：将截断后续内容，实现见 D13）
- 隐私模式开启时：弹窗顶部显示「隐私模式已开启，导出将自动脱敏」（F16 联动）

**2c. 主进程导出管线（D10 同源应用路线）**：
- **打印窗口**：`createPdfWindow()`（隐藏、`contextIsolation` 开）→ dev: `loadURL('http://localhost:5173?export=1&resumeId=<id>')` / prod: `loadFile(dist/index.html, { query })`
- **React 就绪信号**：`did-finish-load` 后 `executeJavaScript` 轮询 `window.__exportReady`（渲染进程导出模式渲染完成后置位），超时兜底 5s（复用 pdf.ts 竞速模式）
- **`textPdf`**：打印窗口内模板渲染（含 `data-redact` 若隐私开）→ `document.fonts.ready`（3s 竞速兜底）→ `printToPDF({ preferCSSPageSize: true, printBackground: true })`
- **`json`**：`ResumeSchema.safeParse` 当前简历 → 序列化含 `schemaVersion` → 落盘
- **「仅第一页」（D13）**：打印前 `executeJavaScript` 注入打印 CSS `overflow:hidden; max-height: A4内容高` → 单页输出
- 目标目录优先级：显式 folderPath > SettingsSchema.export.lastFolder > storage.folderPath > 下载目录；成功后回写 lastFolder
- 异常：用户取消 → `{ canceled: true }`；printToPDF 抛错 → `{ error }` + toast「导出失败」；fonts 超时不阻塞（日志 WARN）
- **字体竞态兜底（R-1）**：`fonts.ready` 只对已注册 FontFace 字体等待；系统白名单走 fallback 无竞态（M2 影响小），v1.1 导入字体必须 FontFace 注册后实测

### 步骤 3：F16 隐私打码（D6 范围扩大）

- 遮蔽字段：`basics.name / headline / phone / email / address / location / website / photo（blur）/ customFields 全部 / infoItems 全部 value`
- CSS：`[data-redact='on'] .redact-field { filter: blur(6px); user-select: none; }` + `::after { content: '████'; }`；照片 `filter: blur(12px)` + 尺寸占位
- 只改渲染层：编辑态不受影响；Zod 数据原样存储；**导出经 D10 同源路线自动继承**（打印窗口渲染时 privacyMode=true 即带 data-redact）
- **打印态实测（P-4，P0 验证项）**：`filter: blur()` 与 `::after` 在 `printToPDF` 中行为未验证——**第一套模板产出即实测**：导出脱敏 PDF 打开逐项核对（非仅看预览）。若 blur 打印态失效，兜底 = 打印时 `visibility: hidden` + ████ 纯占位（不依赖 filter）

**3d. 常驻提示**：状态栏「隐私模式已开启」文案（`t('status.privacyOn')`）+ 图标高亮

## 五、验收标准（G.3 双轨）

**用户旅程验收**（UI 轨，`XM_UI_SMOKE=1` 扩展）：
1. 打开示例 → 顶栏切模板（classic/modern/compact）→ 预览即时变化（**L1 假功能必须消失**）
2. 调整排版滑杆（含新 headerSize）→ 预览实时刷新 → 一键恢复 → 回落模板预设（**TDD：L4 先红后绿**）
3. 顶栏导出 → 弹窗出现（含「内容约 N 页」）→ 选文字版 PDF + 目标位置 → 进度 → 落盘 → 打开 PDF 文字可选中、与预览一致
4. JSON 导出链路进 smoke（printToPDF GPU 假阳性按 G.3 登记）
5. 开隐私模式 → 预览全遮蔽 → 导出 PDF 自动脱敏 → **打开脱敏 PDF 逐项核对（P-4 实测）** → 关闭恢复
6. 内容超一页时导出屏出现「全部导出 / 仅第一页」选项；仅第一页输出单页且内容截断
7. basics 补三区（profile/photo/infoItems）可编辑 → 预览正确渲染
8. 欢迎面板（基础版）出现在首页

**链路验收**（IPC 冒烟，`XM_M0_SMOKE=1` 扩展）：`export:run` textPdf/json 端到端 + 进度事件 + canceled 分支。

**CI 闸门**：typecheck / lint / vitest（新增 registry、LayoutBar reset 语义、redact CSS 作用域、export 契约、页数检测纯函数测试）/ build 三端 / docs-tool selfcheck（ipc-channels 新增 export:* 需同步白名单）。

## 六、风险与边界登记（含终审 6 项实现级风险）

| 项 | 说明 |
|---|---|
| **D10 导出渲染架构风险（终审最高风险）** | 同源应用路线引入"打印模式"分支：App.tsx 需在 `export` 模式跳过 UI 壳/编辑器/Tiptap 挂载，只渲染模板；dev/prod 加载路径双轨；React 就绪轮询若 5s 超时需降级处理。**第一套模板产出即端到端验证打印窗口链路**，失败再评估 SSR 兜底 |
| **模板 store 依赖（D11）** | ClassicTemplate 依赖 `useResumeStore`/`useTranslation`——同源应用路线天然满足（store/i18n 都在应用内初始化）；若未来走 SSR 需 props 化改造，登记为架构债 |
| **隐私打码 blur/::after 打印态失效（P-4）** | `filter: blur()` / `::after content` 在 Chromium 打印管线中未验证——第一套模板产出即实测；兜底 = 打印态 `visibility: hidden` + ████ 占位 |
| **字体加载竞态（R-1）** | `fonts.ready` 仅等待已注册 FontFace 字体；M2 系统白名单走 fallback 无竞态，v1.1 导入字体必须 FontFace 注册后实测 |
| **页数检测准确性（D12）** | scrollHeight ÷ A4 内容高为估算，可能与 printToPDF 实际分页有 ±1 页误差（边距/break-inside 影响）；N=1 边界以打印结果为准，弹窗提示标注"约" |
| **「仅第一页」截断（D13）** | CSS overflow:hidden 截断内容，与「全部导出」内容不连续——UI 已明确标注；用户选此选项默认理解截断语义 |
| **L5 令牌改名波及面（D15）** | `--bg/--surface` → `--background/--surface-card…` 全仓 grep 替换（styles.css + @theme 映射 + 组件 var() 引用），脚本扫一遍防漏 |
| **photo dataURL 体积（D15）** | 压缩 ≤2MB 仍可能数百 KB；主存 JSON/备份 zip 体积增大，可接受（有上限），登记观测 |
| **L7 欢迎面板与 M3 边界** | 基础版不含最近简历区（M3 落），避免与 WP-T1 重复实现 |
| **printToPDF 沙箱 GPU 假阳性** | G.3 口径登记，用户本机实测为准 |
| **modern/compact 与 PDF 标尺对齐** | 仅 classic 对标示例 PDF；modern/compact 视觉验收以 ATS 兼容 + 风格差异达标为准，不做像素级比对 |
| **ATS 静态说明的表述** | 文案需精准：承诺"可正常解析"基于单栏+矢量+嵌入，若未来开放多栏需降级措辞 |
