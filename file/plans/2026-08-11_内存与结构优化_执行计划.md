## 四、调研结论（外部一手来源）

- **Electron 官方**（perf 教程 / process-model / command-line）：模块 just-in-time 加载（Windows 尤其昂贵）；窗口销毁=回收 renderer 进程唯一手段；renderer 动态 import 符合"不过早加载"。
- **Reactive Resume**（同栈简历应用）：PDF 用最小导出入口、TipTap 只包编辑层、react-window 虚拟化、分包——本计划 A3/B2 借鉴。
- **Mark Text muya**：单一文档状态 + 块级渲染（不 N 实例常驻）——B2 异步加载器 + 编辑区不拆 TipTap 借鉴。
- **Joplin**：数据层隔离（Services→Models→Database）+ 大笔记独立进程渲染——photos/ 独立资产目录 + 数据层抽象预留（P3）借鉴。
- **VS Code piece tree**：大对象出堆（35MB→贴近文件大小）——photo 出 JSON 入文件的直接依据。
- **Logseq**：内存库→SQLite 迁移印证"数据层接口先留好"——sqlite 索引延后视体量。
