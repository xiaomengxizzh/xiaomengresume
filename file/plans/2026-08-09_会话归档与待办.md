## 三、关键决策与坑位速查（续接必读）

- **截图脚本必须 `sandbox:false`**（沙箱不支持 ESM preload → electronAPI undefined → 依赖 IPC 视图白屏）。
- **无 layer 原生 CSS 会压制 Tailwind v4 utilities**——`*` reset 只留 box-sizing；CSS 注释勿写 `p-*` 通配（Tailwind 解析报错）。
- **HTML 无效结构**：button 嵌套 label 吞点击（swatch 修复先例）；返回失效 = activeFieldPath 残留（需同时清）。
- **i18n 浅合并踩坑**：`o.ai={...o.ai,...add}` 覆盖子对象——补 key 用深合并。
- **品牌色 `--brand`**：装饰/强调用，不作正文文字色（dark 对比 <4.5 护栏）；4 主题块自包含。
- **修改用户级配置前备份**；临时产物删除前征求同意。
