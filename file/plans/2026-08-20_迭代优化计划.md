## 二、批次详述

### P0-1 拖拽排序可视化（条目级补齐 + 键盘可访问性）
**问题**：模块级拖拽**已实现**（`EditorPane.tsx:998 ModuleDragHandle`，HTML5 DnD 仅手柄可拖，驱动 `layout.sectionOrder`）；头部三块排序字段 `basicsOrder` **已在 schema**（`resume.ts:219`）。**缺口 = 条目级（教育/工作等数组内）拖拽 + 键盘可访问性**。
**解决方案**：
- 条目级拖拽：教育/工作/项目等列表内部支持拖拽调序，`onDragEnd` 一次性 `setField('work', newArray)` 更新整个数组，符合历史栈"提交级入栈"语义（`history.ts:48` 500ms 防抖已合并）
- 实现选型实施时定：**优先扩展现有原生 HTML5 DnD**（ModuleDragHandle 同款，零新依赖）；若键盘/触摸支持不足再评估 `@dnd-kit/sortable`（React.lazy 按需加载）
- 键盘可访问性：保留上下移动按钮 + 补 Alt+Up/Down 快捷键
**关键注意**：
- 拖拽手柄独立，避免与输入框冲突（现有 ModuleDragHandle 先例）
- 稳定 key 用条目 `id`，防索引错乱
**验收**：
1. `cd project && npm run typecheck && npx vitest run`全绿
2. 条目拖拽：Work 内第一条拖到第二条 → 预览顺序更新 → Ctrl+Z 恢复
3. 键盘操作：Alt+Up/Down 可移动模块与条目
**依赖**：目标零新依赖（原生 DnD 扩展）；@dnd-kit 为备选（纯 JS，过 G.2 三问）

### P0-2 字段级校验与空状态引导
**问题**：`email/phone/website`仅宽松schema校验，无即时反馈；空模块缺少引导。

**关键注意**：
- 仅在字段"已触摸"后显示错误；错误提示支持多语言
**验收**：
1. 邮箱输入无效格式 → 失焦后显示红色提示"邮箱格式无效"
2. 空教育模块 → 显示空态引导 → 点击"添加第一条" → 自动滚动并聚焦第一个输入框
3. Ctrl+Z撤销添加 → 空态恢复

### 远期-15 fitToPage 压缩反馈与溢出预警
**问题**：`fitToPage` **已在 schema**（`resume.ts:221`，四项需求批 A-D 落码，等比重排下限 0.6），但触达下限时用户无感知；跨页截断无提示。
**解决方案**：
- 基于既有 `fitToPage` 测量链路：当缩放触达 0.6 下限仍超一页时，LayoutBar/预览显示橙色提示"内容过多，无法压缩至一页"
- 用`ResizeObserver`检测内容是否截断，显示"溢出红线预警"与建议，不自动插入分页符（`pageBreaks` 字段维持不采纳）
**关键注意**：
- A4分页检测不稳定，仅做预警，不自动分页；计算节流 300ms

### 远期-16 导出页数精确测量

**关键注意**：
- 避免引入窗口生命周期管理复杂度
