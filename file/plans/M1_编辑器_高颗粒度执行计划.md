## 9. 复盘结论（2026-08-07 用户反馈"与预期差异很大"后追加 · 不改正文验收基准）

**事故**：本计划验收总标准第一环"打开示例 → 逐分区编辑"从 UI 上无法走通——`newResume` 无 UI 触发点、示例入口缺失、首次启动空简历永不落盘；但 CI 四连绿 + IPC 冒烟全过，M1 被宣告"落码完成"。

**根因四连环**（本计划自身缺陷 + 执行/验证/验收漏洞，均已修订入《项目规范.md》）：
1. **验收标准与落码清单脱节**：验收标准要求"打开示例"，但 §1–§5 清单无任何"入口"工作项；
2. **正文承诺非 checkbox 化**：§5.3"空则欢迎态"在执行中静默降级为"空编辑器"且未进偏差登记（清单里没有该条）；
3. **验证对象错位**：CI + IPC 冒烟验证的是"代码健康/链路通"，不覆盖 UI 入口存在性；
