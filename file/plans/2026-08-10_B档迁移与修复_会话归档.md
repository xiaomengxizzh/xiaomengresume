## 三、坑位速查（续接必读）

- **bundle __dirname 教训（×2）**：electron-vite 主进程单 bundle，`__dirname` 运行时 = out/main（非源码目录）——相对路径必须按 out/main 层级算（preload `../preload`、renderer `../renderer`；初版 `../../` 两次出错）。
- **组件内定义组件（React 陷阱）**：子组件定义在父组件函数体内 → 每次 re-render 新函数引用 → React 视组件类型变化强制重挂 → input 重建失焦（key/结构无法规避）——必须提模块顶层。
- **条件渲染分支结构差异**：空位/有值格 DOM 结构不同 → 创建时 React 重建子树 → 输入失焦——统一结构（invisible 隐藏不移除节点）。
- **`cf.icon || 'pin'` 兜底**：文字标签（icon 空）被兜底 pin 图标（"输入文字显示地址图标"）——改 `?? ''`。
- **infoItems 双数据源**：TagsBlock 编辑 customFields vs 简历显示 infoItems——编辑不生效——迁入统一。
- **spike 与生产差异**：临时脚本自建窗口手动加 preload/绝对路径，与生产 createPdfWindow/相对路径不同 → 漏测（preload 缺失、loadFile 路径 bug）。
- **lock 手动清理**：本环境 pnpm 不可用 → package.json 手动删 + lock 脚本精确清理（166 行，验证 0 残留/结构完整/28 行 snapshots 引用均属 @react-pdf 生态）——**CI frozen-lockfile 为最终验证**。
