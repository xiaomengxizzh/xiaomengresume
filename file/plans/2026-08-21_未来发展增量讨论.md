## 二、用户新想法评估（2026-08-21 提出）

### D1 · AI 功能向导（指导使用 + 索引直达）——**采纳，拆两层**
- **L1 无 AI 引导层（先行）**：① 首启 onboarding 任务清单（新建→填写→选模板→导出 PDF 四步，复用 WelcomeView/EmptyState action 既有机制）；② Ctrl+K 命令面板，搜索功能名直达视图（功能集封闭：零幻觉、零成本、离线可用）；③ 各屏「?」帮助入口。可发现性问题大半靠信息架构解决，L1 先验证。
- **L2 AI 向导（BYOK，后置）**：知识源 = 功能路由表**封闭枚举**；generateObject 只输出 viewId，渲染端 setCurrentView **点击直达**（非文字指路）；清单外问题回答「不知道」防幻觉；本质是智能导航，非聊天机器人。⚠️ 需新增 IPC 契约（冻结区，须审批）。
- 设计红线：禁闲聊、禁自由文本回答产品问题；无 key 时 L2 不可用不影响 L1。
- **交互形态细化（2026-08-21 二轮讨论）**：独立向导按钮 → 点击开**向导弹窗**，弹窗内「选择问题 → 分步指引」：
  - 弹窗壳复用 `ui/dialog.tsx`（受控模态框/Esc 关闭/i18n 已备）；纯渲染层改动，**零契约变更、零新依赖、零 AI**；
  - 内容结构：左列问题分类（入门/导入/AI/导出与设置），右侧该题分步说明；窄宽退化单列（问题列表→步骤面板→返回）；每步可带「前往 →」按钮直调 `setCurrentView`（view 字符串与 NavBar SUBS 表同源，建议抽共享常量+类型约束防漂移）；步骤末尾给「完成标志」（对应旅程验收思想）；
  - 初始问题集 6–8 条：新建简历 / 导入旧简历（PDF·Word）/ 换模板配色 / AI 功能说明（含 BYOK 解释）/ 导出 PDF / 多份简历管理 / 数据存哪（隐私）；
  - 文案全走 F13 i18n（zh/en 对称，check:i18n 强制）；步骤定义 = renderer 内常量文件（topic id + steps[] + 可选 targetView）；
  - **按钮落点定案建议**：主入口 = **NavBar 底部 nav-spacer 上方常驻「使用向导」**（求助场景不可预测须全局常驻；不挤占 resume/ai/settings 三主项信息架构；折叠态不放——会用折叠的是熟练用户）；辅入口 = WelcomeView 欢迎卡第三按钮（首启触点）。不建议 TopBar（? 图标语义混淆「关于」）、不建议四宫格第五卡（破坏定案布局）；
  - 升级路径：同一弹窗底部预留「没找到？问 AI」入口位 = L2 落点，知识源同一路由表。

### D2 · 内置网页版 AI（DeepSeek/豆包网址 + 贴提示词）——**不采纳内嵌浏览器形态，改造为三替代件**
1. **DeepSeek 加入内置服务商**：OpenAI 兼容 API、baseURL 固定，与 volcengine/custom 机制同构零新架构；豆包 = volcengine 已内置。配「无 key 接入向导」（openExternal 打开官网申请页——外链的正当用途）。
2. **场景化预设按钮继续降 prompt 可见度**：polish/intro/match 已是此形态（用户无需懂提示词），按此路线加密场景。
3. **「复制场景提示词（含简历上下文）」按钮 + 隐私提醒**：真想用网页 AI 的用户给单向出口，粘贴到任意工具；可选 shell.openExternal 官网链接。
- **反对内嵌的理由**：① 登录墙/Cloudflare 盾/网站改版 = 持续适配负债，免费开源项目养不起；② Electron 内嵌第三方网页扩大安全面（session/Cookie），且可能违反对方 ToS；③ 产品断点：外部生成的**无结构**文本须手动贴回指定字段，绕过三步核对/AI 白名单全部信任设计——等于把直出方案的缺点引回家；④ BYOK 应用内路径体验严格更优（流式 + 接受/放弃 + 结构化）。

## 三、铁律修订提案（须用户拍板）
- **方案 A（推荐）**：「禁一键生成简历」→「**禁凭空生成，允许受控重构**」。防的三件事均有工程解：编造→三步核对 diff 审查 + 字段白名单 + 数字占位符；同质化→骨架来自用户素材 + 本地模板 + printToPDF；失控→撤销栈 + 版本快照。落地形态 = 快速建档向导（旧简历图片/PDF 或问答访谈 → ImportMap → 三步核对 → 编辑器），与现有导入管线完全同构。
- **方案 B（保守）**：铁律不动，同一套能力以「导入助手增强」名义发布。两者代码路径相同，差异仅在营销口径。

## 四、优先级建议与依赖
