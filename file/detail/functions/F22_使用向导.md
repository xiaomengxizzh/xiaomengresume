> 归属:D6 应用设置与发布 · 落码批次:2026-08-21(B1-B5,计划 `file/plans/2026-08-21_向导弹窗D1-L1_执行计划.md`,讨论稿 `2026-08-21_未来发展增量讨论.md` D1 拍板)

## 需求

降低新用户上手门槛:任何视图下可呼出「使用向导」,弹窗内**选择问题 → 分步指引**,每步可带「前往 →」一键直达对应功能区。设计约束:**纯静态封闭集**——零 AI、零幻觉、离线可用、零 IPC 契约变更、零新依赖(讨论稿 D1-L2 的 AI 问答为后续可选升级,仅留锚点)。

## 交互形态

- **入口(双)**:主 = NavBar 底部(nav-spacer 上方)常驻按钮,collapsed 折叠态不放;辅 = 欢迎页(WelcomeView)第三枚 ghost 按钮。各入口本地 state 各挂一个 `<WizardDialog>`(未开渲染 null,幂等)。
- **弹窗两态**:① 问题列表——按 4 分类分组(快速上手/导入简历/AI 功能/导出与设置)共 7 题;② 步骤面板——编号步骤 + 可直达步的「前往 →」(调 `setCurrentView` 后关弹窗)+ 底部完成标志 hint 行 + 返回。关闭即重置回列表态。
- **7 题**:新建简历 / 导入旧简历(PDF·Word)/ 更换模板配色 / AI 功能说明(含 BYOK)/ 导出 PDF / 多份简历管理 / 数据存哪(隐私)。
