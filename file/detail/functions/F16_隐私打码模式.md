# F16 · 隐私打码模式 — M2

### F16 · 隐私打码模式 — M2
- **需求**：一键遮蔽姓名/电话/邮箱等敏感字段，便于截图发社区求点评、或导出"脱敏预览版"。
- **实现框架**：顶栏「👁 隐私模式」开关 / `Ctrl+Shift+P`；对 basics **全部基本信息**（name/headline/phone/email/address/location/website/photo/customFields/infoItems，2026-08-08 D6 范围扩大）CSS 遮蔽（`████` 占位 + `filter: blur`）；遮蔽作用于**打印态模板**（隐私模式下导出的 PDF 自动脱敏），编辑态表单不受影响；脱敏只改渲染层，**Zod 数据模型不变**。
- **用户视角**：点顶栏「👁 隐私模式」或 `Ctrl+Shift+P` → 预览与导出 PDF 中姓名/电话/邮箱显示为 ████；状态栏常驻「隐私模式已开启」提示。

#### F16 隐私打码落地点（WP-P2 · P 阶段定案）

**切换方式**：

- 顶栏「👁 隐私模式」开关（`lucide-eye` 图标按钮，受控开关，文案走 i18n）一键切换。
- 快捷键 `Ctrl+Shift+P`（`globalShortcut` 或渲染进程 keydown 捕获，不与编辑器快捷键冲突）切换。
- 状态写入 `useResumeStore` 的 `privacyMode: boolean`，**不触碰 Zod 数据模型**（`ResumeSchema` 字段不变，见《项目功能.md》F16）。

**作用域（仅打印态模板）**：

- 脱敏**只改渲染层**：在模板根节点挂 `data-redact={privacyMode ? 'on' : 'off'}`。
- 敏感字段（来自 Zod `basics`：`name` / `headline` / `phone` / `email` / `address` / `location` / `website` / `photo`（blur）/ `customFields` 全部 / `infoItems` 全部 value，2026-08-08 D6 范围扩大）在打印态模板中加 `redact-field` class；CSS 仅在 `[data-redact='on']` 下生效：

```css
[data-redact='on'] .redact-field {
  filter: blur(6px);
  user-select: none;
}
[data-redact='on'] .redact-field::after {
  content: '████';   /* 占位，避免纯 blur 露出尺寸 */
  filter: none;
}
```

- **编辑态表单（EditorPane 受控 Input/Textarea）不受影响**——用户照常看到并编辑真实姓名/电话，脱敏只在预览与导出 PDF（打印态）显现；Zod 数据原样存储。
- 导出 PDF（F5）在隐私模式开启时，主进程渲染 HTML 带 `data-redact='on'`，自动产出脱敏矢量 PDF，无需独立"脱敏导出"按钮。

**常驻提示**：

- 状态栏（功能屏底栏，见《项目功能.md》四）常驻「隐私模式已开启」文案（`t('status.privacyOn')`），图标同步高亮；关闭后消失。与 F13 i18n 一致，中英文均走 key。

**零新依赖**：纯 CSS + store 布尔 + 模板 class 作用域，符合《项目功能.md》F16 与《技术栈.md》对照矩阵（F16 零依赖），不引入任何脱敏库。
