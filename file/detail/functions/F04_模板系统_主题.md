# F4 · 模板系统 + 主题 — M2

> 本文件由 `scripts/split_docs.py` 从《项目功能.md》拆分（2026-08-08 路由化定案）；真相源 = 本文档。

### F4 · 模板系统 + 主题 — M2
- **需求**：多套简历模板可切换，主题（配色 / 字体）可换；**排版参数全开放（2026-08-07 修订：推翻 WP-T4「去间距」）——模板预设 + 用户覆盖**，默认值保证 ATS 兼容。
- **实现框架**：`src/renderer/templates/` 每套模板 = 一个 React 组件（props 为 `ResumeSchema`）；`registry.ts` 注册表（id → 组件 + 缩略图）；主题用 CSS 变量（`--resume-font / --resume-accent / --resume-spacing`），`ThemeProvider` 切换，零组件重复；**间距系数 `--resume-spacing` 恢复为 per-resume 可调**（模板预设 classic 1.0 / modern 1.15 / compact 0.85 仅作默认值）；分页用 CSS `@page` + `break-inside: avoid`。
- **排版参数落点**：`ResumeSchema.layout`（2026-08-07 增补，见 F1 §2.9），**覆盖链：简历 `layout` > 模板预设 > 全局设置初始值**；themeColor per-resume（简历 JSON 内，覆盖 F11 全局 `resumeAccent` 默认）。
- **简历字体选择**：字体来源 = ① 系统字体静态白名单（`src/shared/constants/fonts.ts`，跨平台常见中英文字体名，默认「系统默认」= 现有 fallback 链 `PingFang SC / Microsoft YaHei / Noto Sans CJK SC / sans-serif`）；② 用户导入字体（见 F18 扩展 + 《技术栈.md》§3.7.4 手段 D）。
- **编辑器内模板控制（2026-08-07 增补）**：模板控制**不锁在模板设置页**，编辑器内随时可调（F2 混合范式控制区的一部分）——M1 = 顶栏最小控制（模板切换 + 主题色 + 字体）；M2 = 完整排版参数面板（字号/行距/间距/页边距滑杆，即调即见，右侧预览实时刷新）。
- **ATS 提示（2026-08-07 增补）**：**默认模板值保证 ATS 兼容**（单栏/标准标题/系统字体/文字可选，设计保证）；用户修改排版时**分级提示**——见下「F4 修订：排版参数开放 + ATS 提示」。
- **用户视角**：顶栏「模板」下拉列出带缩略图的模板，选中即换预览版式；「主题」切换配色 / 字体；编辑器内可随手调排版参数，右侧预览实时变化；预览区多页按 A4 自动分页、条目不被截断。
- **待拍板**：v1.0 内置套数（建议 3 套）、L2 模块排序是否进 v1.0（建议不做，见《项目实现情况.md》#5）；字体方案见 #23（已按默认建议落定：静态白名单 + 导入字体）。

#### F4 修订：排版参数开放 + ATS 提示（2026-08-07 用户拍板 · 推翻 WP-T4「去间距」）

> **决策背景**：用户拍板开放全排版参数（理由：投递时可能不需要经过 ATS 检测）。技术事实支撑——**ATS 解析读 PDF 文本层，字号/行距/间距/页边距/主题色不进文本层、不影响解析**；真正影响 ATS 的是多栏布局（文本流乱序）、emoji/图标字体、无文本层、字体未嵌入——项目已全部防住（单栏定案 / lucide SVG 图标 / printToPDF 矢量 / 字体嵌入）。

- **覆盖链**：`ResumeSchema.layout`（per-resume）> 模板预设（classic 1.0 / modern 1.15 / compact 0.85 仅作默认系数）> 全局设置初始值。
- **分级提示**：
  - 排版参数微调（字号/间距/行距/页边距/主题色）→ **温和提示**："已自定义排版。ATS 系统通常可解析，投递前可一键恢复模板默认"。
  - 结构性修改（多栏布局 / 图标 / 字体源，v1 模板为单栏不开放布局切换，此档为将来预留）→ **强提示**："此改动可能影响 ATS 解析，投递 ATS 岗位前建议恢复默认"。
- **一键恢复模板默认**（v1 必有）：提示旁提供按钮，恢复 = 清空 `layout` 字段（回落模板预设），简单可靠。
- **ATS 检测器**（M2+ 导出链路顺带）：轻量检查（单栏 / 文本层 / emoji 扫描 / 字体嵌入），导出 PDF 时给结果；**v1 不做完整检测器**，只有提示 + 一键恢复。
- **入口双处**：顶栏「模板」下拉（F4 规划）+ 编辑器内控制面板（M1 顶栏最小 / M2 完整滑杆），均写 `layout` 字段、进 F3 撤销栈。

#### F4 模板系统落地点（WP-P2 · P 阶段定案）

**模板套数（v1.0 拍板）**：v1.0 内置 **3 套模板**，均为**单栏布局**（ATS 默认兼容，设计保证，非独立检查界面），差异化仅在版式密度与视觉节奏，不引入双栏/图文混排等 ATS 风险结构：

| id | 定位 | 版式特征 | 适用场景 |
|---|---|---|---|
| `classic` | 经典单栏 | 传统分段、姓名大字 + 居中横线分隔、节标题全大写 | 传统行业 / 外企 / 学术 |
| `modern` | 现代单栏 | 左对齐节标题带左侧色条（accent）、留白更大、条目间距宽松 | 互联网 / 设计 / 通用 |
| `compact` | 紧凑单栏 | 行距收紧、节标题小号加粗、一页内承载更多条目 | 经历丰富 / 一页上限严 |

三套共享同一套组件化渲染函数（姓名块 / 节容器 / 条目卡片），仅通过主题 CSS 变量与少量布局开关（`--resume-spacing`、标题样式 class）区分，避免组件重复。

**L2 模块排序（明确不进 v1.0）**：`sectionOrder` / `hidden` 拖拽显隐与排序能力列为**增强候选（v1.x 增强）**，**v1.0 不做**。v1.0 所有模板按固定 section 顺序渲染（`basics → summary → education → work → projects → skills → certificates → languages`），不暴露用户自定义排序/隐藏入口；数据模型无需为 L2 预留字段（保持干净）。

**模板注册表 `registry.ts`**（位于 `src/renderer/templates/registry.ts`）：

```ts
// src/renderer/templates/registry.ts
import type { ComponentType } from 'react'
import type { ResumeSchema } from '@shared/schema/resume'
import ClassicTemplate from './classic/ClassicTemplate'
import ModernTemplate from './modern/ModernTemplate'
import CompactTemplate from './compact/CompactTemplate'
import classicThumb from './classic/thumb.png'
import modernThumb from './modern/thumb.png'
import compactThumb from './compact/thumb.png'

export interface TemplateMeta {
  id: 'classic' | 'modern' | 'compact'
  nameKey: string        // i18n key，禁硬编码中文
  component: ComponentType<{ data: ResumeSchema }>
  thumbnail: string      // 缩略图 dataURL / 资源路径
}

export const templateRegistry: Record<TemplateMeta['id'], TemplateMeta> = {
  classic: { id: 'classic', nameKey: 'template.classic', component: ClassicTemplate, thumbnail: classicThumb },
  modern:  { id: 'modern',  nameKey: 'template.modern',  component: ModernTemplate,  thumbnail: modernThumb },
  compact: { id: 'compact', nameKey: 'template.compact', component: CompactTemplate, thumbnail: compactThumb },
}

export const defaultTemplateId: TemplateMeta['id'] = 'classic'
```

模板下拉组件消费 `templateRegistry` 渲染带缩略图选项；切换仅改 `useResumeStore` 中的 `templateId`，`PreviewPane` 按 id 取组件渲染。

**间距系数模板预设（T 阶段 #23 定案 · 2026-08-07 修订为开放）**：三套模板间距系数作为**默认预设值**（用户不调 = 用默认，保证 ATS 兼容）；**2026-08-07 起用户可在编辑器内调整**（写入 `ResumeSchema.layout`，per-resume 覆盖，见 F4 修订）：

| 模板 id | `--resume-spacing` 预设 | 视觉节奏 |
|---|---|---|
| `classic` | `1.0` | 传统分段、姓名大字 + 居中横线分隔 |
| `modern` | `1.15` | 留白更大、条目间距宽松 |
| `compact` | `0.85` | 行距收紧、一页内承载更多条目 |

**主题 CSS 变量方案（默认预设 + 字体选择，与模板正交）**：

```css
.resume-root {
  --resume-font: 'Noto Sans CJK SC', 'PingFang SC', 'Microsoft YaHei', sans-serif; /* 默认指向内嵌 OFL 黑体；可被用户字体选择覆盖（系统白名单或导入字体 family） */
  --resume-accent: #2563eb;   /* 节标题色条 / 链接 */
  /* --resume-spacing：默认取模板预设，用户可调后由 layout 字段覆盖（2026-08-07 修订） */
  font-family: var(--resume-font);
}
```

`ThemeProvider`（轻量 context + 写入 `.resume-root` 的 style 变量）负责切换主题；每套模板预设一个默认主题，"主题=换皮"走 L1（已定案必做），零组件重复。`--resume-font` 同时承接 F16 / 中文字体策略（见 #7 口径与 C 段 + 《技术栈.md》§3.7.4 手段 B/D）。

**简历字体选择（模板/主题界面三项之一）**：下拉 = 系统字体静态白名单（含「系统默认」选项）+ 用户已导入字体列表（来自 `SettingsSchema.importedFonts`，删除项见 F18 扩展）；选中写入 `ResumeSchema.layout.resumeFont`（family 名，per-resume；缺省回落全局/模板默认），经 `--resume-font` 作用于当前模板预览与打印态。**间距控件已恢复开放**（2026-08-07 修订，见 F4 修订小节）。

**分页 `@page` 口径**（铁律见《项目规范.md》4.3 /《技术栈.md》§3.7）：

```css
@media print {
  @page { size: A4; margin: 15mm; }
  .resume-section, .resume-entry { page-break-inside: avoid; }
  .resume-section + .resume-section { page-break-before: auto; }
}
```

条目跨页不硬截（`page-break-inside: avoid`），章节分页交给 Chromium 自然流动；M2 第一套模板即用 A4 三端验证（`size: A4; margin: 15mm` 一致、`page-break-inside: avoid` 中文字段跨页不截）。

**ATS 默认兼容设计保证口径**（设计保证，非独立功能，见《项目功能.md》ATS 段）：三套模板一律**单栏布局 + 标准 section 标题（真实文本 `h2`，非图片/艺术字）+ 内嵌 OFL 矢量字体 + 文字可选中**；矢量导出（F5）天然契合 ATS 与企业投递系统读取。ATS 被筛的核心风险来自"非标准/图片化/双栏"版式，"模板=打印"架构 + 内置模板库从设计上规避，故不设置独立 ATS 检查界面/角标/导出卡片。
