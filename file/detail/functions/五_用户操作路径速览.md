# 五、用户操作路径速览

> 本文件由 `scripts/split_docs.py` 从《项目功能.md》拆分（2026-08-08 路由化定案）。

## 五、用户操作路径速览

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 第一次打开 | 进入主界面（导航中枢），右侧默认欢迎面板（图标 + 超大标题「欢迎回来」+ 副语）；左侧栏引导点选 | F11/F12 |
| 关闭欢迎 / 分区面板 | 点右上角窗口控制按钮（3 枚 24×24 细线图标：放到后台 / 全屏 / 关闭，常态 `#666` 灰、Hover 变深 + 浅灰底，距顶/右 12px，模态/面板语境）关闭当前面板 | 主壳 |
| 之后每次打开 | 同样进入主界面；「简历 → 打开 / 最近」恢复上次编辑 | F11 自动保存与恢复 |
| 点左侧栏「简历 / AI / 设置」 | 右侧切换分区选单（简历 **5 固定卡片**：新建空白简历 / 打开或最近 / 导入 / 管理多份简历 / 岗位目录；导出与模板入口在编辑器顶栏；AI：语法纠正 / 自我介绍 / 简历润色 / 匹配打分 / 岗位目录；设置：外观 / AI 设置 / 简历存储位置）；第一张卡片与左导航「简历」菜单项**顶部拉齐** | F11/F2/F6/F10/F7–F9/F12/F18/F21/F19 |
| 点分区选单条目 | 进入对应功能屏 | F2/F4/F5/F6/F10/F11/F16 等 |
| 编辑（核心日常） | 表单卡片 + 右侧实时预览；富文本内加粗/换行；条目重排；Ctrl+Z/Y | F2/F3/F13 |
| 换模板/主题 | 下拉缩略图即换预览；主题切配色/字体/间距；A4 自动分页 | F4 |
| 隐私打码 | 顶栏👁 或 Ctrl+Shift+P；预览与导出 PDF 脱敏 | F16 |
| 导出（开导出屏） | 顶栏「导出」→ 导出屏：4 格式卡片 + 目标位置（默认上次目录） | F5 |
| 选格式导出 | 选 1 张卡片 → 目标位置已填 → 「导出」→ 进度条 → 落盘完成 | F5 |
| 改目标文件夹 | 点「选择文件夹」即时改；下次默认记忆 | F5 / F21 / #22 |
| 导出文字版 PDF | 矢量 PDF，文字可选，与预览一致；隐私模式自动脱敏 | F5 / F16 |
| 导出 JSON | 当前简历 `.json`（含 schemaVersion），确定性 | F5 |
| 导出图片版 PDF / 图片 | v1.1：逐页截图合成 PDF / 逐页 PNG·JPG | F5（v1.1） |
| 导入旧简历 | 三步核对向导（PDF 文本 / 图片扫描件 / Word / JSON） | F6/F10 |
| AI 辅助 | 润色（流式对比）/ 语法（原位标记）/ 匹配度（分数+建议） | F7/F8/F9 |
| 设置 | 外观（含语言）/ AI 设置（四服务商 + 全局参数）/ 简历存储位置 / 检查更新 | F18/F12/F21/F13/F4/F14 |
| 设置 → 外观 | 4 色主题单选（浅色/深色/暖色/环保）+ 深色跟随系统开关 + 语言（中文/English）二选一（F13，#24），300ms 实时预览 | F18 / F13 |
| 设置 → AI 设置 | 四服务商 tab（API Key / 获取 Key 链接 / 模型 ID / 启用）+ 全局参数（温度/最长上下文/系统提示词） | F12 / F11 |
| 设置 → 简历存储位置 | 查看当前文件夹 → 更改位置（自动迁移全部简历）/ 重置默认 / 打开文件夹 | F21 |
| 简历 → 岗位目录 | 右侧切换岗位目录管理屏（列表/新建/编辑/删除，字段：名称/投递时间/岗位要求）+ 绑定简历列 | F19 |
| 新建 / 编辑岗位 | 表单弹窗填名称 / 投递时间 / 岗位要求 → 保存写入 `userData/jobs/<id>.json` | F19 |
| 删除岗位 | 确认弹窗 → 删除；有简历绑定时提示 | F19 |
| 岗位目录 → 绑定简历 | 岗位目录每行「绑定简历」列反查渲染该岗位绑定的简历名，可点跳转打开 | F19 |
| 编辑器绑定岗位 | **（已移除）** 绑定/解绑集中到 AI 屏顶栏「岗位」选择器（多值 add/remove，写 `boundJobIds`） | F19 |
| 简历管理列表 | 列表展示多份简历（新建/打开/复制/删除），**不再显示岗位列** | F11 |
| AI 屏顶栏选择器 | 顶栏「当前简历」选择器（全部简历）+「岗位」选择器（所选简历 boundJobIds 对应岗位，可 +绑定/解绑）；未选简历/未绑岗位时润色与打分禁用并提示 | F7 / F9 / F20 / F19 |
| AI 四分区 | AI 辅助屏四分区共享「当前简历」选择器；润色/匹配以所选简历为输入、岗位 requirements 注入；未选简历/未绑岗位时对应入口禁用 | F7 / F8 / F9 / F20 |
| AI 提示词设置 | 设置屏「AI 提示词」区编辑 / 保存 / 刷新还原四套提示词 | F11 |
