### F3 · 撤销 / 重做 — M1
- **需求**：编辑过程可 Ctrl+Z / Ctrl+Y，防止误操作。
- **实现框架**：`src/renderer/store/history.ts` 自维护轻量历史栈（结构化克隆快照，上限 50 步）；"提交级"变更（失焦/回车/按钮）入栈，500ms 防抖合并。**2026-08-08 修订为统一撤销栈**：Tiptap 禁用内部 UndoRedo（`StarterKit.configure({ undoRedo: false })`），Ctrl+Z/Y 全走 store 栈——原「Tiptap 内部栈 + store 栈双栈隔离」存在双向污染（内部 undo 触发 onUpdate → history.record 把撤销前状态压入 store 栈，撤销行为不可预测），统一后撤销语义单一、可预测，代价为富文本撤销粒度=字段级提交（整字段回退、光标回文档头，见《项目实现情况.md》§2.4 偏差 ⑪a）。
- **范围（2026-08-07 扩展）**：快照覆盖**内容字段 + `layout`/`theme`（模板切换、排版参数、主题色调整）**——编辑器内调排版不合适应能 Ctrl+Z 回退。快照 diff 按 F2 数据路径记录（"哪条路径变了"），非整份对比。
- **用户视角**：误删一段/改错了 → `Ctrl+Z` / `Ctrl+Y`，工具栏也有按钮（50 步）；调排版调过头同样能撤销。
