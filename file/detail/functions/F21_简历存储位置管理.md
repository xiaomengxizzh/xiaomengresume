### F21 · 简历存储位置管理（S 批新增）— v1.1 / M5
- **需求**：简历的存储与修改从「隐藏的 C 盘 userData」改为**用户可选的本地文件夹**，打开默认在该文件夹读写；与云盘/同步无关（2026-08-06 用户澄清，原名「同步文件夹」废弃）。
- **实现框架**：`SettingsSchema` 增 `storage: { folderPath?, lastUsedAt? }`；主存 = `<storageFolderPath>/<id>.json`（F11 三件套基准同步迁移，jobs 仍 `userData/jobs/`）；默认 `app.getPath('documents')+'/xiaomengresume'`（可见易找）；设置屏 `settings.storage`：「更改位置」→ `dialog.showOpenDialog` → **自动迁移全部简历**（.json+.bak 拷贝，原子完成后提示，不删旧文件）；「重置为默认」（二次确认）；信息行 = 当前路径（`…` 截断 + tooltip）/ 打开文件夹 / 上次使用时间。
- **用户视角**：设置 → 简历存储位置 → 看到当前文件夹（默认 `文档/xiaomengresume`）→ 「更改位置」选一个本地文件夹（如 D 盘）→ 已有简历自动全部搬过去 → 之后打开应用都在那儿读写。
- **护栏**：零云盘 SDK；纯本地文件夹无同步服务干扰（仅用户自选同步盘内目录时存在同步相关风险，用户自担）；F11 三件套不降级（`.tmp` 锁 / `.bak` 轮转 / `backup:export` 范围 = `storageFolder/ + jobs/`）；守《项目规范.md》五 架构铁律 1（文件 IO 全在主进程）。

#### F21 落地形态（WP-S3 · S 阶段定案 · 方案 B 主存迁移）
- **IPC（冻结于 `src/shared/`）**：`storage:choose` / `storage:get`（`{ defaultPath, currentPath, exists }`）/ `storage:set`（应用新位置并自动迁移，返回 `{ migrated }`）/ `storage:reset`（重置为默认，同样迁移）/ `storage:open`（`shell.openPath`）；preload 暴露 `window.electronAPI.storage.{choose,get,set,reset,open}`。
- **迁移逻辑**（`src/main/files/storage-migrate.ts`）：校验新位置可写 → 拷贝旧位置全部 `.json`+`.bak.*` → 成功后切 `storage.folderPath` 并提示迁移数 → 失败不切换、旧数据不动；**绝不删除旧文件**。
- **i18n key**：`settings.storage.title/defaultFolder/currentFolder/chooseFolder/resetConfirm/migrated/migrateFailed/lastUsed/openFolder`（zh/en 同构）。
