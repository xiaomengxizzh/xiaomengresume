### F19 · 岗位目录与简历绑定（R 批新增，T 批多值扩展）— v1.1（数据层 M1 顺带落码）
- **需求**：维护一份「岗位目录」（岗位名称 / 投递时间 / 岗位要求），每份简历可绑定**多个岗位**（`boundJobIds`，uuid 数组）；AI 润色 / 匹配打分以「所选简历 + 所选岗位」为语境（贴岗润色、JD 打分）；岗位目录行展示该岗位绑定的全部简历名（可点跳转打开）。数据层扩展 M1 顺带落码（`boundJobIds` 仅增不改、零迁移），UI 与 AI 消费随 v1.1（M3）。
- **AI 定位**：岗位目录服务于 F7/F9/F20 的「选岗语境」与「贴岗重点」，本身不生成任何简历内容。
- **T 批决策（对应 #21）**：`boundJobId`（单值）→ `boundJobIds: string[]`——项目零代码零数据，直接改定义、`schemaVersion` 保持 1、迁移骨架预留 case 注释（无历史包袱）；AI 四分区（语法纠正 / 自我介绍 / 简历润色 / 匹配打分）**共享同一「当前简历」选择器**，岗位选择器选项 = 所选简历已绑岗位。

#### F19 数据层落地点（WP-R1 · R 阶段定案）

> 对应待拍板 #12/#13（按默认建议落定）：`requirements` 用纯文本 `string`；岗位存 `userData/jobs/<id>.json` 与简历平行、纳入备份 zip。

**1. `JobSchema`（`src/shared/schema/job.ts`，Zod v4）**

```ts
import { z } from 'zod/v4';

// appliedAt 复用 F1 的 DateStr 形态（宽松 YYYY-MM / YYYY，允许空串）
const DateStr = z.string().regex(/^\d{4}(-\d{2})?$/, '日期格式应为 YYYY 或 YYYY-MM').or(z.literal('')).optional();

export const JobSchema = z.object({
  id: z.uuid(),                                   // 岗位唯一 id（uuid v4）
  name: z.string().min(1),                        // 岗位名称（展示名，文件命名依据）
  appliedAt: DateStr,                             // 投递时间，复用 F1 DateStr
  requirements: z.string(),                       // 岗位要求（纯文本，供润色/打分消费）
  createdAt: z.string(),                          // ISO 8601，主进程写入
  updatedAt: z.string(),
});
export type Job = z.infer<typeof JobSchema>;
export function createEmptyJob(name = ''): Job { /* 新 uuid + 当前时间戳 */ }
```

**2. 岗位存储（`src/main/files/job-store.ts`）**：`userData/jobs/<id>.json`，仿 resume-store 生命周期——**新建**（uuid + `createEmptyJob` 写入）、**重命名**（仅改 `name`，文件 `<id>` 不变，原子写回）、**复制**（深拷贝赋新 uuid + 刷新时间戳）、**删除**（`fs.unlink` + 同步删 `.bak` 序列，**不级联删除**绑定该岗位的简历）。复用 `.tmp` 锁（崩溃恢复）与 `.bak` 轮转（自动备份），岗位同样受数据安全三件套保护。

**4. IPC 契约（冻结于 `src/shared/`，与 `resume:*` 同域）**

```ts
ipcRenderer.invoke('jobs:list'): Promise<Array<{ id: string; name: string; appliedAt?: string }>>;
ipcRenderer.invoke('jobs:get', { id: string }): Promise<Job | null>;
ipcRenderer.invoke('jobs:save', { job: Job }): Promise<Job>;
ipcRenderer.invoke('jobs:delete', { id: string }): Promise<boolean>;
ipcRenderer.invoke('resume:bindJob',   { resumeId: string; jobId: string }): Promise<void>;  // 向 Resume.boundJobIds 追加 jobId（去重）
ipcRenderer.invoke('resume:unbindJob', { resumeId: string; jobId: string }): Promise<void>;  // 从 Resume.boundJobIds 移除 jobId
ipcRenderer.invoke('resumes:list'): Promise<Array<{ id: string; name: string; updatedAt?: string; boundJobIds: string[] }>>;  // 摘要增 boundJobIds，供岗位侧反查
```

通道名冻结于 `src/shared/ipc-channels.ts`；preload 暴露 `window.electronAPI.jobs.{list,get,save,delete}` 与 `window.electronAPI.resume.{bindJob,unbindJob,list}`（替换原 `bind/unbind`）。`resume:bindJob/unbindJob` 复用 `resume:save` 写入与数据安全链路，不另起写路径；主进程 handler 校验 `resumeId`/`jobId` 均为 uuid（路径穿越防护）。

**5. `backup:export` 范围扩展**：打包目录由 `userData/resumes/` 扩为 **`userData/resumes/ + userData/jobs/`**（含 `.json` + `.bak`），数据安全三件套口径不变、**不降级**；排除项不变（不含 logs、不含 API Key 明文）。

#### F19 用户视角（WP-R2 · R 阶段定案，T 批 WP-T2 多值扩展）

- **「岗位目录」选单条目**：左侧栏「简历」分区选单新增 `job.dir`（岗位目录）条目 → 进入独立**岗位目录管理屏**（⑭）。
- **岗位目录管理屏 · 绑定简历列**：列表每行新增「绑定简历」列，由渲染进程用 `resumes:list` 摘要的 `boundJobIds` **反查**该岗位绑定的全部简历名（过滤 `boundJobIds` 含本 `job.id` 的简历），可点跳转打开对应简历；无绑定显示占位（i18n `job.boundResumes.none`）。见线框 ⑭。
- **AI 屏顶栏统一选择器（T 批 #21 落定）**：AI 辅助屏顶栏统一放置「当前简历」选择器 + 「岗位」选择器，四分区（语法纠正 / 自我介绍 / 简历润色 / 匹配打分）共享：
  - 「当前简历」选择器：选项 = 全部简历（`resumes:list`），默认空（`ai.currentResume.placeholder`）。
  - 「岗位」选择器：选项 = **所选简历 `boundJobIds` 对应的岗位名** + 固定「+ 绑定岗位」项（弹岗位目录选择，经 `resume:bindJob` 追加）/「解绑」项（经 `resume:unbindJob` 移除单项）；未选简历时禁用。
  - 未选简历 / 未绑岗位时，**润色与匹配打分入口禁用并提示**（`ai.polishDisabledHint` / `ai.matchDisabledHint`）；语法纠正与自我介绍仅依赖「当前简历」，未选简历时禁用并提示（`ai.noResumeHint`）。
- **【删除】原「简历管理列表岗位名列」**（原 bullet 4：每条简历右侧「岗位」列）——**用户明确不需要**，本批移除（见线框 ⑥ 移除该列）。绑定关系改由岗位目录「绑定简历」列呈现。
- **原「编辑器绑定岗位选择器」**（原 bullet 3 单值 Dropdown）**由 AI 屏顶栏统一选择器取代**：绑定/解绑集中在 AI 屏顶栏「岗位」选择器（多值 add/remove），编辑器不再单独承载绑定 Dropdown。
- **i18n key 候选（新增，前缀 `job.boundResumes.*` 与 `ai.*`，zh-CN 默认、en 对称、禁硬编码中文）**：
  - `job.boundResumes.column`（绑定简历列标题） / `job.boundResumes.none`（该岗位未绑定简历）
  - `job.bind`（绑定岗位） / `job.unbind`（解绑）
  - `ai.currentResume`（当前简历） / `ai.currentResume.placeholder`（请选择简历）
  - `ai.job`（岗位） / `ai.job.placeholder`（请选择岗位）
  - `ai.noResumeHint`（请先选择简历） / `ai.polishDisabledHint`（请先选择简历与岗位） / `ai.matchDisabledHint`（请先选择岗位）
  - 保留既有 `job.dir` / `job.new` / `job.name` / `job.appliedAt` / `job.requirements` / `job.edit` / `job.delete` / `job.deleteConfirm` / `job.column` / `job.unbound`
