### F13 · 国际化（zh / en）— M0 起
- **需求**：中英双语界面，**默认中文（`zh-CN`），不跟随系统解析**；语言切换入口置于**设置 → 外观（`settings.appearance`）**；选「English」仅切换**全 UI 文案**（经 i18n 切换），**用户可自由编辑的简历内容（姓名 / 经历 / 技能等 `ResumeSchema` 字段）不受影响**。
- **实现框架**：**M0 即立脚手架**（i18n 初始化 + 两空壳 JSON，结构对称）；所有文案走 `t('key')`，**禁硬编码中文**（纪律见《项目规范.md》4.1）；`SettingsSchema.language: 'zh-CN' | 'en'`（默认 `zh-CN`，定义见《技术栈.md》§3.11）；语言入口在 `settings.appearance` 屏（与主题 / 字体控件并列，见 F18）。切换走 `i18n.changeLanguage(locale)`，仅作用于 **UI 文案层**（所有 `t('key')` 渲染），**不触碰 Zod 简历数据模型**（`ResumeSchema` 字段内容由用户掌控、与 locale 无关）；模板示例文案按语言走。
- **用户视角**：设置 → 外观 → 语言「中文 / English」**二选一** → 整个界面 UI 文案即时切换；简历中已填写的姓名 / 经历 / 自我评价等用户内容**原样不变**（AI 润色 / 匹配打分等 locale 参数由设置注入，不改变用户数据）。
