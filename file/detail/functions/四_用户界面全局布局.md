## 四、用户界面全局布局（用户视角）

启动后是一个本地桌面窗口（无浏览器地址栏、无登录页）。**界面分两层：应用主壳（导航中枢）与功能屏**：

- **主壳（导航中枢，启动即显示）**：**悬浮面板 / 模态窗形态**，内部 **2:8 纵向分割**（左导航 ~20% / 右内容 80%）；**侧边栏 = 独立悬浮卡片**（仅左侧圆角 + 向右投影分层），右内容区背景 = **主题「主背景」色**（与侧栏/卡片不同色）；**高度完全动态自适应**（由右侧分区选单固定卡片 + 上下留白撑开，无固定高度）；**顶部无任何全局大标题**。**启动时右侧默认显示欢迎面板（图标 + 居中超大标题「欢迎回来」+ 副语，右上角窗口控制按钮）**；点左侧栏才切换右侧为该分区功能选单（**入口卡片：主题「卡片」色、无描边仅投影、纯文字无图标，hover 上浮变暗 / active 下沉**，第一张卡片与左导航首菜单项**顶部拉齐**），再点条目进入对应功能屏。左侧栏可收起。

> **界面视觉形态（用户视角概述）**：柔顺卡片风——**主题主背景 + 悬浮侧栏卡片 + 卡片无描边仅投影 + 圆角 12px + hover 上浮变暗 / active 下沉** + 充足留白；主壳呈悬浮面板 / 模态窗形态，功能屏为模态弹窗 / 独立面板，右上角带窗口控制按钮（放到后台 / 全屏 / 关闭，常态 `#666`、Hover 变深，距顶/右 12px）。**详细视觉规范（布局比例 / 动态高度规则 / 顶部拉齐线 / 颜色令牌 / 4 色主题 / 窗口控制按钮双态 / 字体令牌 / 与 F4 模板主题正交护栏等）见《技术栈.md》3.15.1，本处不重复**。

#### D1 核心编辑 · 编辑器屏

- **编辑器**：左/上编辑区（EditorPane）分多个 section 卡片；右/下预览区（PreviewPane）实时渲染最终简历外观，所见即所得，也是导出 PDF 的同一份底稿。
- **功能屏顶栏**：应用标题、当前简历名、模板/主题切换、隐私模式开关、导出按钮、设置入口、**撤销/重做按钮**（F3）。
- **功能屏底栏/状态条**：自动保存状态（已保存/保存中）、当前语言、AI 状态指示、隐私模式提示。

#### D2 模板与导出 · 模板/导出屏

- **模板**：下拉缩略图即换预览；主题切配色/字体/间距；A4 自动分页（F4）。
- **导出屏**（顶栏「导出」进入）：4 格式卡片（文字版 PDF / 图片版 PDF / 图片 / JSON）+ 目标位置（默认上次目录 / 简历存储位置）（F5）。

#### D4 AI 辅助 · AI 屏

- AI 辅助屏四分区共享「当前简历」选择器（F7/F8/F9/F20）；润色（流式对比）/ 语法（原位标记）/ 匹配度（分数+建议）/ 自我介绍（基于简历已有事实提炼，禁编造）（F7–F9/F20）。
- 顶栏统一「岗位」选择器：所选简历 `boundJobIds` 对应岗位；未选简历/未绑岗位时润色与打分入口禁用（F7/F9/F20 + F19）。

#### D5 简历与岗位管理 · 岗位目录 / 最近 / 存储

- **岗位目录屏**（左侧栏「简历」分区选单「岗位目录」进入）：列表/新建/编辑/删除岗位（名称/投递时间/岗位要求）+ 绑定简历列（可点跳转）（F19）。
- **最近简历列表屏**（「打开或最近」）：按活动时间倒序展示全部简历（名称 + 最后编辑时间），提供打开/复制/重命名/删除（F11，T 批 WP-T1）。
- **简历存储位置**：为设置区 `settings.storage` 屏，详见 D6。

#### D6 应用设置与发布 · 设置区功能屏

- `settings.appearance`（外观）：4 色主题 + 深色跟随系统 + 语言二选一 + 界面字体/导入字体（F13/F18）。
- `settings.templates`（模板设置，M5-5 新增第 4 屏）：**图书式翻书选择界面**——横排三槽位（中间当前模板完整突出大卡 / 左右相邻模板缩小露边，左右箭头循环切换）；卡片零按钮，点击任意卡进入该模板**独立编辑视图**（返回按钮回图书；左编辑面板 = 6 数值滑杆 + 模板字体 + 色板 + 节标题三选一 + 还原/保存，右真实渲染预览）；默认模板三选（A6，新建预选即时生效）。
- `settings.ai`（AI 设置）：四服务商 tab + 全局参数 + R 批 AI 提示词区（F11/F12）。
- `settings.storage`（简历存储位置）：查看当前文件夹 → 更改位置（自动迁移全部简历）/ 重置默认 / 打开文件夹（F21）。
- F11 数据安全三件套、本地日志、备份/导出、诊断、关于保留原位（M5）。

> 所有数据存本机、不上云；完全免费、无水印、无订阅；AI 需自填 API Key（离线可用，只是 AI 功能离线不可用）。
