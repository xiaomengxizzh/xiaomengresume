### F18 · 界面外观主题（S 批新增）— M1/M5
- **需求**：应用 UI（非简历）支持 4 色主题（浅色/深色/暖色/环保），并可选择深色跟随系统；默认浅色不变。**2026-08-06 五次定案：显示名与全量配色按用户新方案替换（见下表），UI 形态对齐用户《UI示例_参考图.html》**。
- **实现框架**：`SettingsSchema` 增 `appearance: 'light'|'dark'|'beige'|'green'`（默认 `light`）+ `appearanceMode: 'fixed'|'system'`（默认 `fixed`，仅 `dark` 跟随系统）；shadcn + Tailwind v4 按 `data-theme` 切 4 组令牌；主进程 `nativeTheme.themeSource` 仅在 dark+system 时切 `'system'`；preload/主进程首帧前注入 `data-theme` 防 FOUC；设置屏 `settings.appearance`（4 选 1 单选卡 + mode 2 选 1 + 300ms 实时预览）。**新增界面字体令牌 `--ui-font`**：作用于应用壳 / 功能屏全局 `font-family`，与简历 `--resume-*` 严格正交（PreviewPane 强制白纸不受影响）；界面字体与「导入字体」入口见下「F18 字体系统扩展」。
- **用户视角**：设置 → 外观 → 选浅色/深色/暖色/环保，界面即时换肤；勾选「深色跟随系统」后，深色主题随系统明暗自动切换（其余三色固定）。
- **护栏（守 3.15.1）**：4 色仅作用于应用 UI；`PreviewPane` 强制白纸、F4 三套模板不随 appearance 变（与 `--resume-*` 严格正交）；窗口控制按钮双态硬编码（常态 `#666` / Hover `#1A1A1A`·dark `#E5E5EA`，2026-08-06 五次定案替换原 CloseX 约定）不随主题色变；**防绿字护栏**：每个 `[data-theme="x"]` 块自包含声明全部 6 令牌（`--sidebar/--background/--card/--foreground/--selected/--border`），禁把 green 的 `--foreground` 设 `:root` 默认，dark 下断言 `--foreground` 非绿（M1/M5 落码 check，根因见《项目规范.md》二·配色职责边界）。

#### F18 字体系统扩展（WP-T4 · T 阶段定案）

> 对应待拍板 #23（已按默认建议落定）。字体数据层 + 令牌 + SettingsSchema 字体字段归属本包；UI 布局与 `language` 字段归 WP-T5（外观屏整合布局不在本包范围，仅引用其入口）。

**1. 双范围字体**
- **UI 字体（`--ui-font`，应用壳 / 功能屏）**：全局 `font-family`，由 `SettingsSchema.uiFont` 指定 family；作用于侧栏 / 卡片 / 表单等所有应用 UI。**PreviewPane 强制白纸、不继承 `--ui-font`**（守白纸正交，与 F18 护栏一致）。默认 `uiFont = 'system default'`（= 系统 UI 字体 fallback 链）。
- **简历字体（`--resume-font`，模板消费）**：由 `SettingsSchema.resumeFont` 指定 family，覆盖于 `.resume-root` 的 `--resume-font`；可被用户从系统字体白名单或导入字体中选择（见 F4 修订）。

**2. 系统字体静态白名单（v1.0）**
- 源：`src/shared/constants/fonts.ts`——按平台枚举常见中英文字体名（Windows / macOS / Linux 各一组），如 `PingFang SC`（macOS）、`Microsoft YaHei`（Windows）、`Noto Sans CJK SC` / `WenQuanYi Micro Hei`（Linux）、`Segoe UI` / `system-ui` 等。
- 默认「系统默认」项 = 现有 fallback 链：`'PingFang SC', 'Microsoft YaHei', 'Noto Sans CJK SC', sans-serif`。
- **v1.0 不引入 font-list 枚举**（运行期探测已装字体），列为 v2 候选（#23）。白名单为零依赖静态常量。

**3. 导入字体入口（数据层 + 主进程）**
- 设置屏「外观 / 导入字体」按钮（`fonts.import`，见 i18n）→ 渲染进程 `ipcRenderer.invoke('font:import')` → 主进程 `dialog.showOpenDialog`（filters：`ttf / otf / woff / woff2`，单文件上限 20MB）→ 复制到 `userData/fonts/<id>.<ext>`。
- 主进程注册自定义协议 `protocol.handle('font', ...)` 服务本地字体文件，渲染进程动态注入 `@font-face { src: url('font://<id>.<ext>') }`；清单写入 `SettingsSchema.importedFonts: Array<{ id, fileName, family, addedAt }>`。
- **许可提示（导入时必弹）**：文案 `fonts.importLicenseWarning`——「字体许可由用户自担；仅本机使用，不随应用重新分发」。勾选确认后方可导入。
- 移除导入字体：`SettingsSchema.importedFonts` 删对应项 → 主进程删除 `userData/fonts/<id>.<ext>` 并注销 `@font-face`。

**4. 导出嵌入（与 §3.7.4 手段 B 同机制）**
- 导入字体经 Chromium 打印管线在 `printToPDF` 时**自动子集嵌入** PDF（与内嵌 OFL 黑体手段 B 同机制），导出 PDF 自包含字体、跨端一致；**许可由用户自担**（导入时已提示仅本机使用、不随应用重新分发）。

**5. i18n key（前缀 `fonts.*`，zh/en 同构，禁硬编码中文）**
- `fonts.systemDefault` / `fonts.uiFont` / `fonts.resumeFont` / `fonts.import` / `fonts.importedFonts` / `fonts.importDialogTitle` / `fonts.importFilterHint` / `fonts.importLicenseWarning` / `fonts.removeFont` / `fonts.fontFamily`。
- 注：「语言」二选一控件归 WP-T5（`settings.appearance.language*`），本包不写。

#### F18 外观屏整合形态（WP-T5 · T 阶段扩展，对应 #24）

> `settings.appearance` 功能屏整合 T4（字体）+ T5（语言）与 S 批既有（主题），为**单一外观设置屏**。本包（WP-T5）仅负责**布局整合与 `language` 字段**，字体控件由 WP-T4 定义，本包只引用、不定义字体数据层（uiFont / resumeFont / importedFonts 归 T4）。

**屏内布局（自上而下分区，柔顺卡片风）**：

| 分区 | 控件 | 归属 | 说明 |
|---|---|---|---|
| 主题区 | 4 色主题单选卡（浅色/深色/暖色/环保）+ 深色跟随系统开关 + 300ms 实时预览 | S 批 F18（WP-S1） | 已有，五次定案配色与显示名 |
| 语言区 | **语言二选一**（中文 / English）单选卡 | **WP-T5（本包）** | `SettingsSchema.language`，默认 zh-CN，不跟系统；选英文仅切 UI 文案 |
| 字体区 | 界面字体下拉（系统默认 + 已导入字体）+ 导入字体按钮 | WP-T4 | 本包仅布局占位引用，控件定义归 T4；注意 `uiFont`（应用 UI 字体）与 `resumeFont`（简历模板字体）字段所有权归 T4，不与本包 `language` 重叠 |

- **位置关系**：语言区紧邻主题区之下、字体区之上（或按视觉节奏与字体区并列于同一外观屏卡片列），三者同属 `settings.appearance`，用户在**一处**完成主题 / 语言 / 字体设置。
- **护栏（守本包边界）**：`language` 字段**只影响 UI 文案层**（i18n），**绝不**写入 / 改写 `ResumeSchema` 简历数据；与 F4 简历模板主题（`--resume-*`）、T4 字体字段严格正交，互不耦合。
- **i18n key**：在 WP-S1 既有 `settings.appearance.title/light/dark/beige/green/mode/fixed/system/previewHint` 基础上**新增** `settings.appearance.language/zh/en`（zh/en 同构，禁硬编码中文）；标签文案走 key，不写死中文字符串。
- **用户视角补充**：设置 → 外观 → 选 4 色主题即时换肤 + 勾「深色跟随系统」+ 选语言「中文 / English」+（T4）选界面字体 / 导入字体，全部设置同屏完成、300ms 实时预览；语言切换仅换 UI 文案，简历内容不变。
