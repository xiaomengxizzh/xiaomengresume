### 2026-09-08 — 开发环境 Windows→Linux 迁移 + 纯浏览器 Web 预览模式（dev:web）

- **迁移背景**：开发机由 Windows 切换至 Linux（Wayland 桌面）。依赖重装后实测发现两个迁移坑：① pnpm 11（`packageManager` 锁定）对依赖构建脚本默认收紧，`electron` postinstall 静默未跑 → `node_modules/electron/dist` 缺失，`electron-vite dev` 报 `Error: Electron uninstall`（报错无指向性）；修复 = 手动 `node node_modules/electron/install.js`（`.npmrc` 已配 npmmirror 镜像，秒级完成；`pnpm-workspace.yaml` 的 `onlyBuiltDependencies` 白名单本就在，疑似首次安装时构建脚本未触发，复装后恢复正常）。② dev 启动撞 Linux SUID 沙箱（`chrome-sandbox` 需 root:4755），属环境层问题，见下条 dev:web 绕开方案；桌面端真机验证待后续（可用 `sudo chown root:root chrome-sandbox && sudo chmod 4755 chrome-sandbox` 或 userns 路径解决）。
