## 一、功能总览

| 编号 | 功能 | 功能域 | 里程碑 | 关键技术栈 |
|---|---|---|---|---|
| F1 | 简历数据模型（Zod schema） | D1 核心编辑 | M1 | Zod、版本化 JSON |
| F2 | 编辑器（混合范式） | D1 核心编辑 | M1 | React + shadcn/ui + Tiptap v3 + Zustand |
| F3 | 撤销 / 重做 | D1 核心编辑 | M1 | Zustand + 自维护历史栈 |
| F4 | 模板系统 + 主题 | D2 模板与导出 | M2 | React 组件 + CSS 变量 + Tailwind v4 |
| F5 | PDF 导出（矢量） | D2 模板与导出 | M2 | `printToPDF` + CSS `@page` |
| F16 | 隐私打码模式 | D2 模板与导出 | M2 | CSS 脱敏（零新依赖） |
| F6 | PDF 导入 + AI 映射（三步核对） | D3 数据导入 | M4 | unpdf + `generateObject` + Zod |
| F10 | AI vision 导入（图片/扫描件） | D3 数据导入 | M4 | AI SDK 多模态 + 视觉守卫 |
| F7 | AI 润色（辅助定位） | D4 AI 辅助 | M3 | `streamText` + 主进程 + IPC |
| F8 | AI 语法检查 | D4 AI 辅助 | M3 | AI SDK + class 作用域标记 |
| F9 | 岗位匹配度打分 | D4 AI 辅助 | M3 | `generateObject` + Zod |
| F20 | AI 自我介绍生成 | D4 AI 辅助 | M3/v1.1 | AI SDK `streamText` + 接受/放弃（守 AI 定位铁律） |
| F11 | 持久化与设置 | D5 简历与岗位管理 | M1/M5 | electron-store + userData JSON |
| F19 | 岗位目录与简历绑定 | D5 简历与岗位管理 | v1.1（数据层 M1 顺带） | Zod JobSchema + `userData/jobs/` + `boundJobId` |
| F21 | 简历存储位置管理 | D5 简历与岗位管理 | v1.1/M5 | 主存迁移（`<storageFolderPath>/<id>.json`）+ `dialog.showOpenDialog` + 自动迁移 |
| F12 | API Key 管理（BYOK） | D6 应用设置与发布 | M5 | safeStorage（含 Linux 降级） |
| F13 | 国际化（zh/en） | D6 应用设置与发布 | M0 起 | react-i18next |
| F14 | 自动更新 | D6 应用设置与发布 | M5 | electron-updater + GitHub Releases |
| F15 | 打包分发 + 开源发布 | D6 应用设置与发布 | M5 | electron-builder + GitHub Actions |
| F18 | 界面外观主题 | D6 应用设置与发布 | M1/M5 | shadcn + Tailwind v4 令牌（`data-theme` 4 态）+ `nativeTheme`（仅 dark 跟系统） |

> **AI 定位铁律**：F7/F8/F9/F20 只做"辅助编辑"，**不做"一键生成简历"**——招聘官已广泛吐槽 AI 简历同质化，辅助定位是差异化的一部分（调研结论）。F20 自我介绍仅基于简历已有事实提炼（禁编造简历外事实）。

> **功能域分组依据**：D1–D6 分组与编号冻结（F17 空号不复用）已拍板，见《项目实现情况.md》§2.2 #26；分组归属见本文件 §一 / §三 / §四 域标注。
