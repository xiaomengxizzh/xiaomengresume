排版系统

建立 Type Scale

问题 全局 15px 基础，各处 11/12/13/15/16/17/22px 散用，缺乏系统化 Type Scale

5 档 Type Scale

Display
28/800 页面大标题
Title
18/700 区域标题 / 卡片标题
Body
14/500 正文内容，表单标签，导航主项
Caption
12/500 辅助文字，徽标，下拉选项
Micro
10/600 标注 · 分类 · 序号

行高与字重规范

/* Design Tokens — Typography */
:root {
  /* Font Size Scale */
  --text-display: 28px;
  --text-title: 18px;
  --text-body: 14px;
  --text-caption: 12px;
  --text-micro: 10px;

  /* Font Weight */
  --font-bold: 800;     /* Display only */
  --font-semibold: 700; /* Titles, Buttons */
  --font-medium: 500;   /* Body, Nav items */
  --font-regular: 400;  /* Descriptions */

  /* Line Height */
  --leading-tight: 1.2;   /* Display / Title */
  --leading-normal: 1.5;  /* Body */
  --leading-relaxed: 1.7; /* Long-form text */

  /* Letter Spacing */
  --tracking-tight: -0.3px;  /* Display */
  --tracking-normal: 0;      /* Body */
  --tracking-wide: 0.5px;    /* Micro / Labels */
}

h1 { font: 800 var(--text-display) / var(--leading-tight); letter-spacing: var(--tracking-tight); }
h2 { font: 700 var(--text-title) / var(--leading-tight); }
p, label, input { font: 500 var(--text-body) / var(--leading-normal); }
.caption, .badge { font: 500 var(--text-caption) / var(--leading-normal); }
.micro, .label { font: 600 var(--text-micro) / 1; letter-spacing: var(--tracking-wide); }

微交互与动效规范

统一动画语言

问题 0.12s~0.4s 散乱；按钮无按压反馈；主题色板选中仅靠 border

3 档动画时长 Token

150ms
FAST
按钮、hover、toggle
250ms
NORMAL
展开、滑入、面板
400ms
SLOW
主题切换、页面过渡

按钮按压效果

← hover 上浮 + active 下沉缩放

CSS 方案

/* 动画时长 Token */
:root {
  --duration-fast: 150ms;
  --duration-normal: 250ms;
  --duration-slow: 400ms;

  /* Easing */
  --ease: cubic-bezier(.4, 0, .2, 1);
  --ease-out: cubic-bezier(0, 0, .2, 1);
  --ease-spring: cubic-bezier(.34, 1.56, .64, 1);
}

/* 按钮按压 */
.btn {
  transition: all var(--duration-fast) var(--ease);
}
.btn:hover {
  transform: translateY(-2px);
  box-shadow: 0 6px 16px rgba(91,106,191,.3);
}
.btn:active {
  transform: translateY(1px) scale(.97);
  box-shadow: 0 2px 8px rgba(91,106,191,.2);
}

/* 主题色板选中增强 */
.color-swatch.selected {
  transform: scale(1.15);
  box-shadow: 0 0 0 3px var(--card), 0 0 0 5px currentColor;
}

/* 全局主题过渡 */
body.theme-transitioning * {
  transition: background-color var(--duration-slow) var(--ease),
               color var(--duration-slow) var(--ease),
               border-color var(--duration-slow) var(--ease) !important;
}
