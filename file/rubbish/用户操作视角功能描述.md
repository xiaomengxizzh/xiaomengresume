# xiaomengresume · 用户操作视角功能描述

> **文档定位**：从「坐在电脑前使用这个桌面软件的人」的视角，描述当前规划中**用户在前端实际能做的操作**、会看到什么、以及每个操作背后对应的功能模块（F1–F16，详见同目录《功能需求清单.md》）。
> **视角假设**：编辑范式采用《功能需求清单》已定案的**混合范式**（结构化字段用表单、富文本字段用 Tiptap 控件、右侧实时预览）。
> **定稿日期**：2026-08-05（2026-08-05 修订：开源免费定位，新增 F16 隐私打码；F17 ATS 提示已移除，默认所有模板兼容 ATS）

---

## 〇、软件长什么样（全局布局）

启动后是一个本地桌面窗口（无浏览器地址栏、无登录页）。**界面分两层：应用主壳（导航中枢）与功能屏**：

- **主壳（导航中枢，启动即显示）**：左侧栏「简历 / AI / 设置」三个分区入口 + 右侧分区面板。**启动时右侧默认显示欢迎面板（仅图标 + 欢迎语）**；点击左侧栏才切换右侧为该分区功能选单，再点选单条目进入对应功能屏。左侧栏可收起。
- **功能屏（点条目进入后）**：如编辑器——**左/上：编辑区（EditorPane）**，简历内容编辑，分多个 section 卡片；**右/下：预览区（PreviewPane）**，实时渲染「最终简历长什么样」，所见即所得，也是将来导出 PDF 的同一份底稿。
- **功能屏顶栏**：应用标题、当前简历名、模板/主题切换、**隐私模式开关**、导出按钮、设置入口、撤销/重做按钮。
- **功能屏底栏/状态条**：自动保存状态（「已保存 / 保存中」）、当前语言、AI 状态指示、**隐私模式提示**。

所有数据存在本机，不上云；**完全免费、无水印、无订阅**；AI 功能需要用户自己填一个 API Key 才可用（离线可用，只是 AI 离线不可用）。

## 一、首次启动 & 日常进入

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 第一次打开软件 | 进入**主界面（导航中枢）**，右侧**默认显示欢迎面板**（仅图标 + 欢迎语）；左侧栏为「简历 / AI / 设置」三分区入口，引导用户点左侧栏开始 | F11 持久化、F12 API Key |

| 点击左侧栏「简历 / AI / 设置」 | 右侧切换为该分区功能选单（简历：新建 / 打开 / 导入 / 管理 / 导出 / 模板；AI：AI 辅助；设置：设置 / API Key） | F11/F2/F6/F10/F7-F9/F12 |
| 点分区选单条目 | 进入对应功能屏（编辑器 / 导入向导 / AI 辅助 / 模板与主题 / 设置 / 简历管理 / 导出 PDF / 隐私 / 模板编辑） | F2/F4/F5/F6/F10/F11/F16 等 |
| 顶栏「文件 → 新建 / 打开 / 复制 / 重命名 / 删除」 | 弹窗选简历；可同时存在多份简历（每份一个本地 JSON） | F11 多份简历管理 |

## 二、编辑一份简历（核心日常）

采用混合范式，**用户面对的不是一整页 Word 式的自由排版，而是一个个结构化的表单卡片**：

- **基本信息卡片**：姓名、电话、邮箱、所在地、个人网站 —— 普通输入框。
- **教育 / 工作 / 项目 / 技能 / 证书 / 语言** 等 section：每个条目是一张子卡片，可「+ 新增条目」「✏️ 复制」「🗑 删除」；日期用日期选择器，选项用下拉框。
- **富文本字段**（如「自我评价」、每条工作/项目的「描述」bullet）：嵌入一个**小型富文本编辑器**（加粗 / 斜体 / 列表 / 链接），不是整页大文档。

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 在任意输入框打字 | 右侧预览区**实时**更新那一栏内容 | F2 编辑器 + 实时预览 |
| 富文本框里加粗/换行 | Tiptap 控件内即时生效；失焦后并入全局历史 | F2 富文本控件、F3 撤销 |
| 拖动 / 调整条目顺序 | 条目重排，预览同步 | F2 条目管理 |
| 切换「中文 / English」 | 整个界面文案 + 模板示例文案切换为对应语言 | F13 国际化 |
| 误删一段 / 改错了 | `Ctrl+Z` 撤销、`Ctrl+Y` 重做；工具栏也有按钮 | F3 撤销/重做（50 步） |

> ⚠️ 用户感知上这是「表单 + 实时预览」，不是自由画布。好处是：排版永远不乱、PDF 永远干净、AI 导入永远有地方填。代价是自由美术排版能力弱（简历本来也不需要）。

## 三、换模板 / 换主题（外观）

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 顶栏「模板」下拉 | 列出几套简历模板（带缩略图），选中即换右侧预览版式；**所有内置模板默认兼容 ATS**（单栏/标准标题/系统字体/文字可选） | F4 模板系统 |
| 顶栏「主题」 | 切换配色 / 字体 / 间距（如商务蓝、极简黑、学术衬线） | F4 主题（CSS 变量） |
| 预览区滚动 | 多页简历按 A4 自动分页，条目不被截断 | F4 分页（`@page` / `break-inside`） |
| 点顶栏「👁 隐私模式」或 `Ctrl+Shift+P` | 预览与导出的 PDF 中姓名/电话/邮箱显示为 ████；编辑表单不受影响 | F16 隐私打码 |

## 四、导出 PDF（交付物）

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 顶栏点「导出 PDF」 | 弹出保存对话框，选路径 → 生成 | F5 PDF 导出 |
| 等待 1–2 秒 | 生成**矢量** PDF：文字可选中、体积小、高清 | F5（`printToPDF`，等字体加载完再出） |
| 打开 PDF | 与右侧预览**完全一致**（模板=打印） | F4/F5 单一事实源 |

## 五、导入已有简历（吃老本）

### 5.1 普通 PDF 导入（三步核对向导）

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 「文件 → 导入 PDF」选文件 | 软件抽文本 → AI 尝试映射到本地模型 | F6 PDF 导入 |
| **第 1 步：看 AI 映射预览** | 展示 AI 识别出的姓名/经历/技能等 | F6 首轮映射 |
| **第 2 步：逐段核对 / 手改** | 左右对照，用户可改错、补缺（向导**不可跳过**，防盲信 AI） | F6 三步核对 |
| **第 3 步：确认写入** | 写入当前简历 store，预览刷新 | F6 写入 |

### 5.2 图片 / 扫描件导入（vision）

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 「导入 → 从图片 / 扫描 PDF」 | 多模态模型识别图片内容，走同一套三步向导 | F10 vision 导入 |
| 若选了不支持视觉的模型 | 客户端直接禁用该选项并提示「需选 Gemini / OpenAI / 豆包」 | F10 视觉模型守卫 |

## 六、AI 辅助（需先填 API Key）

### 6.1 润色

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 选中一段文字 → 点「AI 润色」 | AI 流式改写，**逐字**出现在对比框 | F7 润色（`streamText`） |
| 看对比（原文 vs 润色后） | 「接受 / 放弃」二选一 | F7 接受对比 |

### 6.2 语法检查

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 点「语法检查」 | 问题处**原位**标波浪线（专属 class，不会误清别的高亮） | F8 语法检查 |
| 点标记 | 弹出建议，一键替换 | F8 建议替换 |

### 6.3 岗位匹配度打分

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 粘贴一段「岗位 JD」→ 点「匹配度打分」 | 返回综合分 + 各维度分（卡片/进度条）+ 改进建议 | F9 匹配度打分 |
| 点某条建议「去润色」 | 跳转到对应字段并触发 F7 润色 | F9 → F7 串联 |

## 七、设置（一次性 / 偶尔）

| 用户操作 | 界面反馈 | 对应功能 |
|---|---|---|
| 「设置 → API Key」 | 填 Key + 选模型 / 填 endpoint（豆包需 baseURL）；存本机加密 | F12 BYOK |
| 「设置 → 语言」 | 切换界面语言（同 F13） | F13 国际化 |
| 「设置 → 默认模板 / 主题」 | 设下次新建简历的默认外观 | F4/F11 设置持久化 |
| （若启用）「检查更新」 | 有新版本提示下载；否则完全离线 | F14 自动更新（可选） |

> 密钥加密：Windows/macOS 用系统级加密（`safeStorage`）；少数无密钥环的 Linux 会降级并弹告警，但不会明文裸存。

## 八、打包分发（用户无感，但决定交付形态）

- 用户最终拿到的是 **离线 exe / dmg / AppImage**，或**免安装便携 zip**，双击即用，不依赖服务器。
- 对应 F15 打包（electron-builder）。自动更新 F14 是否启用，取决于是否接受最小静态托管（与「离线」定位需二选一自洽）。

## 九、用户视角的一句话总结

> 一个**开源免费、离线、本地的桌面简历编辑器**：启动即见**导航中枢**（左侧栏「简历 / AI / 设置」+ 右侧默认欢迎面板），点左侧栏切换分区、再点条目进功能屏；编辑器里左边填结构化表单 + 少量富文本，右边实时看成品；换模板主题、导出矢量 PDF、**一键隐私打码后放心发社区**（内置模板默认兼容 ATS）、导入旧简历（三步核对防翻车）、填自己的 API Key 后用 AI 润色/查语法/算匹配度 —— 所有数据都在你电脑里，不上任何云，不花一分钱，无水印不阉割。

**待你拍板的唯一真·分叉（P0）**：第 2 节描述的「表单+实时预览」混合范式是否采用。若改纯 WYSIWYG 或纯表单，第 2 节及 F1/F2/F3/F6 的数据流需重写。
