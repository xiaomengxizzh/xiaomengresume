# 依赖离线缓存说明

本文件与 `deps-cache-reusable.tar.gz`（约 40–60MB）配套：把 `shixi/` 里**已经下载且版本兼容**的 xiaomengresume 依赖打成了离线缓存，避免下次 `pnpm install` 重复下载。

> 生成时间：2026-08-05。格式 `tar.gz` 可保留符号链接（7-Zip / WinRAR / Windows 11 自带 tar / git bash tar 均可解压）。

---

## 一、里面有什么（闭包统计）

- **450 个包、12,626 个文件、原始约 136MB**（压缩后约 40–60MB）。
- 完整包含：React 18.3.1、Tiptap 3.21 全家（core/react/starter-kit/8 个扩展 + `@tiptap/pm` + 18 个 prosemirror 包）、Zod 3.25.76、TypeScript 5.7.3、Vite 7.3.1、@vitejs/plugin-react 5.1.4、esbuild 0.25.4（含 win32-x64 二进制）、Tailwind 3.4.17、postcss 8.5.x、clsx、tailwind-merge、uuid 11、cmdk、concurrently、electron-updater 6.8.9、prettier 3.8.1、streamdown 2.3.0，以及它们的全部传递依赖。

## 二、怎么用

```bash
# 1) 解压（把 .pnpm 内容解到项目 node_modules 下，与已有的合并）
mkdir -p xiaomengresume/node_modules
tar -xzf xiaomengresume/deps-cache-reusable.tar.gz -C xiaomengresume/node_modules

# 2) 正常安装（命中缓存的包直接复用，只下载缺失的）
cd xiaomengresume && pnpm install
```

- pnpm 会校验并**重建** `node_modules` 链接，缓存里的符号链接即使解压时受损也不影响——**包内容（真实文件）才是关键**。
- 若想省事，也可以先用 `pnpm install` 装一遍（缺失包会从 npmmirror 下载），再把缓存解压合并，用于日后重建/备份。
