# 用户定位与画像调研（2026-08-11）

> **定位**：网络调研（12 产品真实爬取 + 营销理论框架）+ 功能倒推 → 用户定位与画像定案（已入《项目介绍.md》三章）。本文件为证据链归档。

## 一、调研证据（一手来源）

### 1.1 简历产品画像标签（curl 直连官网 + GitHub API 实抓，12 成功 / Zety 超时、Teal 403 如实标注）

- **国际商业**：Resume.io（career changers / employment gaps / experienced professionals）、Novoresume（18M+ job seekers，学生档/高管档）、FlowCV（免费极慷慨，多版本+AI 为付费点）、Enhancv（experienced professionals & executives，按职级+行业细分）、Resume Worded（professionals/graduates/students，评分驱动）
- **国内**：超级简历 WonderCV（校招/社招/简历小白/零经验应届/多方向投递）、知页（应届生/转行党/海归/在职跳槽/简历小白，中文最全标签集）、锤子简历（百万职场精英、30+ 行业）
- **开源**：Reactive Resume 40.3k★（隐私+自托管+无账号）、OpenResume 8.8k★（本地浏览器运行、College Student/工程师证言）、Magic Resume 9.7k★（AI 辅助+个人免费）、rendercv 17.3k★（学者+工程师垂直）
- **行业数据**（Novoresume 统计博客）：90% 雇主用 ATS、仅 25% 简历通过、每职位平均 250 份简历、2% 获面试

### 1.2 画像标签汇总（15 个）

应届生/毕业生、简历小白、转行者、空窗期/长期失业者、ATS 筛选中招者、跳槽在职者/加薪族、中高管/资深专家、行业垂直求职者、海归/留学生、被裁再就业者、隐私敏感型、开发者/自托管、零预算求职者、企业/B 端、多方向投递者。

### 1.3 理论框架（权威来源实抓）

- **STP**（HubSpot）：细分（人口/心理/行为/地理）→ 目标 → 定位
- **定位声明句式**（特劳特/里斯 + HubSpot）：For [target] who [need], [brand] provides [benefit] because [reason to believe]
- **Persona**（NN/g + Alan Cooper）：身份/目标/行为/痛点/场景/quote 六要素，主 persona 聚焦
- **JTBD**（Christensen Institute）：功能/情感/社交三维，按情境分组
- **VPC**（Strategyzer）：客户工作/痛点/收益 × 功能/止痛剂/增益器
- 北极星指标（Mixpanel）/ TAM-SAM-SOM（HubSpot）/ 创新扩散早期采用者（Rogers ~13.5%）

## 二、定位演化

1. **旧定位（口号化）**：开源免费 · 隐私优先 · 防盲信 AI 的简历工作台——五个抽象承诺，无具体用户。
2. **倒推画像（功能→需求）**：从项目实际功能（三步核对导入/BYOK/岗位台账/隐私打码/排版自定义）倒推——用户是"有数字素养、注重数据自主、有条理管理求职、对 AI 审视"的求职者。
3. **定案（统一）**：合并"普通求职者"需求导向与功能倒推——**"认真求职的普通人"：入口做轻（模板+表单+填 key 即用），深度做足（自定义/台账/核对）**。对外定位用轻，功能取舍与文案按深度用户设计。
