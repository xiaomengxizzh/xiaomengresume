## 三、分步执行计划

### 步骤 1：F4 模板系统（含 L1/L4/L6/L8 + 2b 缩略图）

**1a. 模板目录重构**：
- `src/renderer/preview/ClassicTemplate.tsx` → `src/renderer/templates/classic/ClassicTemplate.tsx`
- 新建 `src/renderer/templates/shared/`：抽 `SectionBlock / SecTitle / entryHead / fmtDate / Placeholder / CLASSIC_PRESET 类型`（渲染基元，三套模板共享，避免组件重复——F4 规格原话）
- 新建 `src/renderer/templates/registry.ts`：`templateRegistry: Record<TemplateId, TemplateMeta>`（id / nameKey / component / thumbnail / preset），`defaultTemplateId = 'classic'`（规格 §F4 有完整示例）
- 新建 `src/renderer/templates/modern/ModernTemplate.tsx` + `src/renderer/templates/compact/CompactTemplate.tsx`：共享基元 + 布局开关差异化（modern = 左对齐节标题带 accent 色条、留白更大、间距宽松；compact = 行距收紧、节标题小号加粗）。**单栏铁律**：三套均单栏、标准 h2 标题、真实文本（ATS 免疫，见 §四）
- `src/renderer/preview/` 只留 PreviewPane 壳（缩放逻辑）

**1b. 修模板假功能（P0·L1）**：
- PreviewPane（现 BasicPreview.tsx 壳内）按 `resume.layout.templateId` 从 registry 取组件渲染；缺省回落 `defaultTemplateId`
- 三套模板预设系数（F4 定案）：classic 1.0 / modern 1.15 / compact 0.85（`--resume-spacing` 默认值，可被 layout 覆盖）

**1c. CSS 缩略图（2b）**：
- 每套模板一个 `thumb.tsx`（迷你版式：div + 色块模拟姓名行/标题线/条目块），`registry.ts` 的 `thumbnail` 字段指向组件而非 PNG
- 模板下拉（TemplateBar 或 M2 完整面板）渲染带缩略图选项；缩略图可随 themeColor 动态着色
- 理由：零依赖、构建期无图片管线、不随主题变的问题消除；PNG 截图需跑 Electron 管线（重）

**1d. 排版面板扩展（D3 + L4/L6）**：
- LayoutBar 补 headerSize 滑杆（schema 有、CLASSIC_PRESET 有、无控件）
- **修 reset 语义（TDD 红绿先行）**：`reset()` 改为清空 `layout` 的排版覆盖字段（`baseFontSize/lineHeight/pagePadding/paragraphSpacing/sectionSpacing/headerSize`），回落模板预设（不再写死 classic 值）；`templateId/themeColor/resumeFont` 保留用户选择。**先写失败测试**：modern 模板下 reset → 断言回落 modern 预设（而非 classic 值）→ 再修实现（L4 bug 正是无测试的产物，2026-08-08 评估增量 TD-3 采纳）
- 保留「一键恢复模板默认」按钮（UX 需求，与 ATS 无关——D7）
- ATS 提示：**删除 LayoutBar 内动态分级提示**（无触发入口的过度设计）

**1e. BasicsForm 补三区（L8）**：
- `basics.profile`：Tiptap 富文本区（复用 TiptapField）
- `basics.photo`：图片选择（本地文件 → dataURL，或沿用内置 avatar 快捷选项）
- `basics.infoItems`：增删改列表（icon 选择 + label + value，复用 InfoIcons 6 类）

**1f. @page 打印 CSS（L3 前置）**：
- `styles.css` 或模板级：`@media print { @page { size: A4; margin: 15mm; } .resume-section, .resume-entry { page-break-inside: avoid; } }`
- **A4 三端验证趁早**（《项目规范.md》§4.3）：第一套可用模板立即验证 `size:A4; margin:15mm` 一致、中文跨页不硬截、章节分页正确；异常记入模板 README known issues

### 步骤 2：F5 导出（含 L3 + 模态弹窗 D4 + 多页语义 D5）

**2a. IPC 契约**（冻结于 `src/shared/`，照 F5 落地点）：
- `ExportFormat = 'textPdf' | 'imagePdf' | 'image' | 'json'`
- `export:run({ format, folderPath?, imageFormat?, quality? })` → `{ canceled, filePath?, error? }`
- 进度事件 `export:progress`（phase: render/capture/compose/write; ratio）
- preload 暴露 `window.electronAPI.export.run`
- 现有 `print:pdf` 保留（M0 冒烟链路），`export:run` 新增强化

**2b. 导出屏 = 模态弹窗（D4）**：
- 顶栏加「导出」按钮 → 弹窗：4 格式卡片（文字版 PDF ✅ / 图片版 PDF ⏳v1.1 / 图片 ⏳v1.1 / JSON ✅）+ 目标位置（默认 简历存储位置 F21 > 上次记忆 > 下载目录）+ 「选择文件夹」
- 图片版 PDF / 图片 置灰标注「即将在 v1.1 提供」（i18n `export.commingSoon`）
- **页数提示（D5）**：弹窗内显示「内容约 N 页」；N=1 → 直接导出一页；N>1 → 「全部导出（N 页）」默认 + 「仅第一页」（标注：将截断后续内容）
- 隐私模式开启时：弹窗顶部显示「隐私模式已开启，导出将自动脱敏」（F16 联动）

**2c. 主进程导出管线**：
- `textPdf`：隐藏窗口渲染与 PreviewPane 同源模板 HTML（templateId + theme + data-redact）→ `document.fonts.ready`（3s Promise.race 兜底）→ `printToPDF({ preferCSSPageSize: true, printBackground: true })`
  - **字体竞态兜底（2026-08-08 评估增量 R-1 采纳）**：`fonts.ready` 只对已注册 FontFace API 的字体等待；系统白名单字体走系统 fallback 链、无竞态（M2 阶段影响小），**导入字体（v1.1）必须走 FontFace 注册后 `fonts.ready` 才可靠**——风险登记见 §六，v1.1 导入字体落地时实测
- `json`：`ResumeSchema.safeParse` 当前简历 → 序列化含 `schemaVersion` → 落盘
- 目标目录优先级：显式 folderPath > SettingsSchema.export.lastFolder > storage.folderPath > 下载目录；成功后回写 lastFolder
- 异常：用户取消 → `{ canceled: true }`；printToPDF 抛错 → `{ error }` + toast「导出失败」；fonts 超时不阻塞（日志 WARN）

### 步骤 3：F16 隐私打码（含 D6 范围扩大）

**3a. store**：`useResumeStore` 增 `privacyMode: boolean` + `togglePrivacyMode()`（不触碰 Zod 数据模型）

**3b. 顶栏开关**：`lucide-eye` 图标按钮（受控开关，i18n）+ `Ctrl+Shift+P` 快捷键（`useKeyboardShortcuts` 扩展，与现有 Ctrl+Z/Y/Ctrl+Shift+O 不冲突）

**3c. 遮蔽实现**（D6：全部基本信息）：
- 模板根节点挂 `data-redact={privacyMode ? 'on' : 'off'}`
- 遮蔽字段（比 F16 原案扩大）：`basics.name / headline / phone / email / address / location / website / photo（图片 blur）/ customFields 全部 / infoItems 全部 value`
- CSS：`[data-redact='on'] .redact-field { filter: blur(6px); user-select: none; }` + `::after { content: '████'; }`；照片用 `filter: blur(12px)` + 尺寸占位
- 只改渲染层：编辑态表单不受影响；Zod 数据原样存储；导出 PDF 时主进程渲染带 `data-redact='on'` 自动脱敏
- **打印态实测（2026-08-08 评估增量 P-4 采纳，P0 级验证项）**：`filter: blur()` 与 `::after` 在 `printToPDF` 中的行为**未经 Chromium 打印管线验证**——filter 可能被打印引擎降级跳过、::after content 可能不渲染。**第一套模板产出即实测**：隐私模式下导出的 PDF 打开检查姓名/电话/照片是否真实遮蔽（而非仅模糊/漏出）。若 blur 在打印态失效，兜底方案 = 打印时用 `visibility: hidden` + `::after` 纯 ████ 占位（不依赖 filter），实测后定案

**3d. 常驻提示**：状态栏「隐私模式已开启」文案（`t('status.privacyOn')`）+ 图标高亮

## 四、ATS 实况研究结论（2026-08-08 · 5 源交叉验证）

**ATS 本质**：非"筛选门卫"，是快速粗糙的文本提取器——剥纯文本 → 按字段塞数据库（姓名/头衔/日期/技能）→ 供招聘官搜索排序。**不看视觉设计**。

**读取 vs 丢失**：

| 正常读 | 丢失/乱序 |
|---|---|
| 可选中文字（真实文本层） | 图片/图标内文字（0 字符） |
| 单栏 + 标准标题 + 标准字体 | 双栏/表格/文本框/页眉页脚（文本交错或跳过） |
| | 未嵌入自定义字体（缺字形→乱码）；加密 PDF；>2MB |

**关键事实**：**字号/行距/间距/页边距/主题色不进文本层，对 ATS 零影响**（视觉属性）。

**v1.0 架构免疫清单**：单栏定案（防最大杀手）✅ / printToPDF 矢量（文本层天然存在）✅ / SVG 装饰图标不承载信息 ✅ / Chromium 打印自动子集嵌入字体 ✅ / 用户可调参数全不影响 ATS ✅。

**→ 结论（D7）**：分级提示 = 过度设计（强提示档无触发入口）。砍为导出屏静态说明 + 保留一键恢复默认。需修订《项目实现情况.md》#29 拍板记录（F4 修订段落）。

## 五、验收标准（G.3 双轨）

**用户旅程验收**（UI 轨，`XM_UI_SMOKE=1` 扩展）：
1. 打开示例 → 顶栏切模板（classic/modern/compact）→ 预览即时变化（**L1 假功能必须消失**）
2. 调整排版滑杆（含新 headerSize）→ 预览实时刷新 → 一键恢复 → 回落模板预设（**TDD：L4 先红后绿**）
3. 顶栏导出 → 弹窗出现 → 选文字版 PDF + 目标位置 → 进度 → 落盘 → 打开 PDF 文字可选中
4. JSON 导出链路进 smoke（printToPDF GPU 假阳性按 G.3 登记）
5. 开隐私模式 → 预览姓名/电话/照片全遮蔽 → 导出 PDF 自动脱敏 → **打开脱敏 PDF 逐项核对遮蔽效果（P-4：blur/::after 打印态实测，非仅看预览）** → 关闭恢复
6. basics 补三区（profile/photo/infoItems）可编辑 → 预览正确渲染
7. 欢迎面板出现在首页

**链路验收**（IPC 冒烟，`XM_M0_SMOKE=1` 扩展）：`export:run` textPdf/json 端到端 + 进度事件 + canceled 分支。

**CI 闸门**：typecheck / lint / vitest（新增 registry、LayoutBar reset 语义、redact CSS 作用域、export 契约测试）/ build 三端 / docs-tool selfcheck（ipc-channels 新增 export:* 需同步白名单）。

## 六、风险与边界登记

| 项 | 说明 |
|---|---|
| printToPDF 沙箱 GPU 假阳性 | G.3 口径登记，用户本机实测为准 |
| **隐私打码 blur/::after 打印态失效（P-4，2026-08-08 评估增量）** | `filter: blur()` 与 `::after content` 在 Chromium 打印管线中的行为未验证——第一套模板产出即实测；兜底 = 打印态 `visibility: hidden` + ████ 占位（不依赖 filter） |
| **字体加载竞态（R-1，2026-08-08 评估增量）** | `fonts.ready` 仅等待已注册 FontFace API 的字体；M2 系统白名单走系统 fallback 无竞态，**v1.1 导入字体必须 FontFace 注册后 `fonts.ready` 才可靠**，落地时实测 |
| modern/compact 与 PDF 标尺对齐 | 仅 classic 对标示例 PDF；modern/compact 视觉验收以 ATS 兼容 + 风格差异达标为准，不做像素级比对 |
| L5 令牌改名波及面 | `--bg/--surface` → `--background/--surface-card…` 需全仓 grep 替换（styles.css + tailwind @theme 映射 + 组件 var() 引用），用脚本扫一遍防漏 |
| 隐私打码扩大范围 | customFields/infoItems 全遮蔽可能误伤用户想展示的内容——脱敏只影响渲染层，JSON 数据不变，可一键关闭，风险可控 |
| ATS 静态说明的表述 | 文案需精准：承诺"可正常解析"基于单栏+矢量+嵌入，若未来开放多栏需降级措辞 |
| 欢迎面板 | 若与 5 卡首页冲突，按 §3.15.1 原样（「欢迎回来」+ 最近简历），不新增第五卡 |
