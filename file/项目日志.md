## 项目定位

xiaomengresume 是一个**开源免费（MIT）、离线本地桌面简历编辑器**（Electron + Vite SPA），定位「开源免费 · 隐私优先 · 防盲信 AI 的简历工作台」。核心能力：

- 结构化 + 富文本**混合编辑**、实时 A4 预览
- 多套模板 / 主题切换、**隐私打码模式**（内置模板默认兼容 ATS，设计保证，无单独检查界面）
- **矢量 PDF 导出**（文字可选、与预览一致）
- PDF / 图片**导入**（AI 三步核对，防盲信）
- BYOK 的 **AI 润色 / 语法检查 / 岗位匹配度打分**（辅助定位，禁"一键生成简历"）
- 数据全部存于本机 `userData`，无登录、无服务器、无订阅、无水印
